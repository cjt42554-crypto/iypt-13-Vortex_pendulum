# 程序成熟基线

本目录是涡流摆四层研究平台的当前程序基线，采用 TypeScript、Vite 和 Vitest 工具链。

## 目录与入口

- [`src/`](src/)：核心模型、求解器、分析和界面源码。
- [`tests/`](tests/)：自动化测试。
- [`scripts/`](scripts/)：模拟、分析、桌面启动和文档检查脚本。
- [`public/`](public/)：静态资源。
- [`package.json`](package.json)：运行命令、开发依赖和 Node.js 版本要求。
- [`index.html`](index.html)：Vite 页面入口。

## 基本运行

需要 Node.js 22 或更高版本：

```bash
npm ci
npm run dev
npm run validate
```

`npm run validate` 汇总单元测试、构建、桌面检查、端到端测试和文档检查；它仍不等同于装置级物理验证。

## 程序契约

- 源码、配置、测试和脚本共同定义一个可复现版本；运行结果必须记录模型身份、配置和环境。
- 构建产物、临时输出、大体积结果和候选修订不直接混入成熟源码。
- 新实现默认进入 [`../90_候选工作区/current/`](../90_候选工作区/current/)；只有明确映射并复验的组件才回写本目录。
- 被接受的验证材料按类别归档到 [`../03_项目资料/`](../03_项目资料/)。
- 当前资格和下一步见 [`../00_项目控制/STATUS.md`](../00_项目控制/STATUS.md)。
