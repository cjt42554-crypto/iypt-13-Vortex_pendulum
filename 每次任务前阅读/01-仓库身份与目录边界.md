## 4. 文件身份规则

- 文件名、目录名、修改时间和“最终”“高保真”“已完成”等文字都不能单独证明权威性。
- 活动候选以 `未提交修改/当前任务/` 为唯一入口。
- 当前管理文档是活动权威；`审查与复现/**/原始同步包` 和 `历史审查` 是绑定旧提交的冻结证据，不应被当成当前命令或当前路径说明。
- `未提交修改` 表示未晋升，不表示不得 Git 提交。阶段成果必须通过 GitHub 保存，才能供不同会话接力。
- `node_modules`、`dist`、coverage、缓存和临时文件不是权威源码，不应提交。

## 5. 科学证据边界

- 前向候选、二维截面参考和结构分析候选必须保持模型身份分离。
- 二维单相完整圆 CFD 不是三维自由表面装置预测。
- 未经装置标定的闭合参数只能是先验或候选参数。
- 只有真实运行和适用域内验证才能升级证据等级；失败、未知、NO-GO 和未执行必须原样保留。
