# 每次任务前阅读

本目录是 Codex、ChatGPT Pro 和其他协作者的唯一强制接力入口。开始任何工作前，请依次完整阅读：

1. [`01-仓库身份与目录边界.md`](./01-仓库身份与目录边界.md)
2. [`02-当前状态与下一步.md`](./02-当前状态与下一步.md)
3. [`03-工作验证与晋升规则.md`](./03-工作验证与晋升规则.md)
4. [`../未提交修改/当前任务/README.md`](../未提交修改/当前任务/README.md)

默认只允许在 `未提交修改` 中工作。未经用户明确批准，不得修改、覆盖或晋升 `01-最终理论`、`02-模拟程序`、`03-项目资料`。

若这里的交接状态与实时 Git 分支、HEAD、工作区或远端状态不一致，以实时 Git 证据为准：先报告漂移，停止可能覆盖内容的操作，不要自行选择一个看起来较新的目录。

以后用户可以只给新会话下面这句话：

> 请从当前 GitHub 仓库继续。先完整阅读 `AGENTS.md`、`每次任务前阅读` 中的全部文件和 `未提交修改/当前任务/README.md`；默认只在 `未提交修改` 中工作，未经明确批准不得修改三个成熟目录。
