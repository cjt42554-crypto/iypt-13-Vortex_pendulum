# 实验前最小准备

软件里的合成例用于确认操作和数值计算。还没有本装置的标定与留出数据，科学结论仍为 **NONE**。下一步是记录装置并开始小规模测量，不需要继续扩大计算平台。

## 先准备这些信息

| 内容 | 最小记录 | 放到哪里 |
| --- | --- | --- |
| 装置身份 | 装置编号、日期、照片、主轴方向；确认只有圆柱入水且没有碰壁/槽底 | 本目录按装置编号建文件夹 |
| 几何与质量 | 圆柱半径、上下端到转轴距离、转轴到水面的高度、水深、槽宽、观测标记力臂；整个随动总成的质量、质心和干转动惯量 | [装置模板](../02_模拟程序/experiments/templates/apparatus-calibrated.template.json) |
| 机械与摩擦 | 弹性恢复关系、黏性阻尼；需要真实停住时测双向静阈值与动摩擦矩，保留测量方法和不确定度 | 装置模板；SS 增加 `support.staticFrictionTorque`、`support.kineticFrictionTorque`，单位 `N*m` |
| 流动与时间 | 水温/物性、圆柱上游流速及变化、水深与转轴高度；视频帧号或共同时间轴 | 原始视频/传感器文件及其说明 |
| 运动记录 | `runId,time,theta`，SI 单位为秒和弧度；角度由图像转换时保存长度标尺、零角、轴方向和转换步骤 | [轨迹模板](../02_模拟程序/experiments/templates/trajectory.template.csv) |
| 标定和留出划分 | 哪些工况用于标定、哪些完全留出，初态和观测通道、验收量 | [预测计划模板](../02_模拟程序/experiments/templates/prediction-plan.template.json) |

原始文件保留不改，派生 CSV 单独保存。`sigma` 是对应观测量的不确定度；没有依据就留空，不能拿任意误差条代替测量。只有位移时必须绑定实际标记点力臂，不能把位移当角度。先做一段短录制，确认运动周期、零速停留和脱粘时刻都能分辨，再固定采集设置。

## 按这个顺序做小试验

1. **无流机械检查**：静态恢复和正反向低速摩擦，再做少量不同初始幅值的自由释放。先确认装置保持单自由度，静水与空气中的差别有记录。
2. **固定体与规定运动**：固定体记录增长/衰减过渡；需要分离位移、速度和加速度耦合时采用至少不同频率的规定运动。只有一条饱和曲线或单频记录，不能分别确定全部尾流参数。载荷相位需要与运动共用时钟。
3. **限定湿区**：只在实际覆盖的正湿面积、湿跨及流速/角度组合内作预测。最小湿跨由有效标定范围确定；试验中干出、再入水、碰壁、破波或明显多模态记录须标记。它们可以是模型失效证据，不能拿模型外推后段继续拟合。
4. **冻结后测留出**：填好装置、系数与计划后生成冻结配置，再取得留出结果。看过留出后若调参，旧留出就不能继续称盲预测，必须另留新的验证数据。

选择 SS 时，系数包 `modelId` 和 `wakeGauge.modelId` 同时采用 SS 身份，提供静/动阈值；选择 DW 时还要采用 `relative-flow-normal-wet-width` 的阻力系数及相应覆盖；组合时两项都需要。当前数值闭合接受常数摩擦阈值和常数方向阻力系数，不支持任意角度函数或任意三维水动力。几何方向宽度准确不代表阻力系数已经测准。

## 软件先试一次即可

在 `02_模拟程序` 内：

```bash
npm run simulate:forward -- \
  --config public/examples/vortex-pendulum-ss-dw-synthetic.json \
  --output /tmp/vortex-synthetic-result.json \
  --csv /tmp/vortex-synthetic-result.csv
```

桌面页面可直接导入同一 JSON，查看粘滑末态、有效区间和终止原因，导出保留完整身份。这个文件明确是 **synthetic-only**，不能改个标签用于装置预测。正式模板保持待填写状态；[输入、迁移与诊断说明](../02_模拟程序/experiments/README.md) 给出实际命令。

当装置记录、摩擦测量、流速/运动时间序列到齐后，先核对单位、域覆盖和数据划分，再进行标定与残差检查。二维 CFD 保持独立定性参考；没有装置标定和真正留出之前，不报告已验证的振幅、功率、起振阈值或预测精度。
