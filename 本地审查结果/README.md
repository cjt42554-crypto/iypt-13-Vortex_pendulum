但对抗性检查发现了两项会阻止正式合入的问题：

1. 结构线性化会对已经超出系数标定域的平衡点照常返回特征多项式；
2. 二维条带恰好共面于自由液面时，会被误判为“完全浸没”并允许单相完整圆 CFD。

另有一项次要输入有限性问题：过大但仍为有限正数的 `activationFraction` 可以通过入口验证，却在平方运算后产生 `NaN`。
