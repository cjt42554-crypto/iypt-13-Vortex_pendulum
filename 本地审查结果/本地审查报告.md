## 4. 逐项审查结果

### 4.1 干湿尾流连续化：代数修正通过

原模型在 `02-模拟程序/src/solvers/forward/model.ts` 中使用：

```ts
const wakeReferenceSpeed = projectedArea > 1e-15 ? flowSpeed : 0;
```

这会在湿投影面积刚越过 `1e-15 m²` 时，把尾流参考速度从 0 直接切换为完整来流。

对抗性几何设置：

- 圆柱底端在 `theta=0` 时恰好接触水面；
- `wakeReal=0.02`；
- `wakeImaginary=-0.01`；
- 来流已完成爬升。

关键结果：

| `theta` | 湿投影分数 | 原尾流角频率 | 候选尾流角频率 | 原 `d(wakeReal)/dt` | 候选 `d(wakeReal)/dt` |
|---:|---:|---:|---:|---:|---:|
| `0` | `0` | `0` | `0` | `-0.04` | `-0.04` |
| `1e-9` | `5.357142857e-12` | `3.560471674` | `4.097494347e-20` | `+0.039584346` | `-0.04` |
| `1e-6` | `5.356821393e-9` | `3.560471674` | `4.097002608e-14` | `+0.039584077` | `-0.0399999999999991` |

因此：

- 原实现的确存在有限跳变；
- 候选激活在干态极限下连续趋于 `dA/dt=-A/tau_w0`；
- Pro 关于这一确定性缺陷的诊断和代数修正是有效的。

但新闭合仍是研究者选择：

\[
a_w(\lambda)=
\frac{\lambda^2/(\lambda^2+\lambda_a^2)}{1/(1+\lambda_a^2)}.
\]

`activationFraction=0.05` 没有被理论或实验唯一确定。默认竖直部分浸没工况的湿投影分数约为 `0.785714`，当前激活约为 `0.998457`，因此新闭合主要修改接近干湿边界的动力学，对默认工况影响很小。

本审查只能判定“连续性修复成立”，不能判定“这个特定激活函数就是真实物理”。

## 5. 阻断正式合入的发现

### F-01 Major：结构谱缺少适用域硬门

#### 位置

```text
04-P0预测链闭合修正版/src/structure/equilibrium.ts:270-299
```

#### 问题

`linearizeForwardAtEquilibrium` 只检查：

- Newton 是否标记收敛；
- 残差是否小于固定绝对门限。

它没有检查：

- 冻结配置是否通过配置验证；
- 平衡点的 `COEFFICIENT-OOD`、`ANGLE-LIMIT`、`SOLID-CONTACT`、`INERTIA-SINGULAR`、`RAPID-INFLOW` 等守卫；
- 五点差分中 `X*±h`、`X*±2h` 是否越过模型域边界。

#### 确定性复现

使用默认参数并冻结：

```text
flowSpeed = 0.05 m/s
diameter  = 0.006 m
nu        = 1.004e-6 m^2/s
```

得到：

\[
Re=298.804780876\ldots > Re_{\max}=250.
\]

前向守卫明确报告：

```text
COEFFICIENT-OOD margin = -48.80478087649402
```

但候选结构函数仍返回：

```text
returnedSpectrum = true
residualNorm     = 0
characteristic  = finite
```

#### 影响

这会使用户对一个数学上是平衡、但系数包无资格解释的点继续做特征值、Hurwitz、Hopf 或参数扫描。“残差小”不等于“模型有效”。

#### 必需修正

正式硬门应为：

```text
验证冻结配置
→ 求 F(X*)=0
→ 验证平衡残差
→ 验证 X* 的全部适用域守卫
→ 验证所有差分模板点不越域
→ 才允许返回 Jacobian/谱
```

若差分模板跨越边界，应明确拒绝，或使用有独立误差研究的单侧导数；不得静默评估域外系数。

### F-02 Major/Moderate：自由液面共面条带被判为完全浸没

#### 位置

```text
04-P0预测链闭合修正版/src/highFidelity/strip-wetting.ts:30-37
04-P0预测链闭合修正版/src/highFidelity/strip-wetting.ts:45-57
```

#### 问题

近竖直分支使用：

```ts
if (Math.abs(sine) < 1e-12) {
  return axialCoordinate >= pivotHeight ? 1 : 0;
}
```

当：

```text
theta                  = 0
stripAxialCoordinate   = pivotHeight = 0.07 m
```

整个条带截面恰好共面于自由液面。它不是位于液体内部的完全浸没圆，但候选返回：

```text
wetFraction = 1
state = full
supportedByCurrentSinglePhaseCfd2d = true
```

极小倾角后：

| `theta` | `wetFraction` | 分类 | CFD 允许 |
|---:|---:|---|---|
| `0` | `1` | `full` | 是 |
| `1e-13` | `1` | `full` | 是 |
| `2e-12` | `0.5` | `partial` | 否 |
| `1e-10` | `0.5` | `partial` | 否 |

因此新“只接受完全浸没”硬门在退化边界上自身存在错误允许和分支跳变。

另外，`classifySectionWetting` 默认把 `wetFraction >= 1-1e-8` 视为 `full`。这会把仍存在小但真实干帽的截面当成完整浸没圆。

#### 影响

当用户把代表条带放在水线附近，当前单相二维圆柱场可能在不具备其几何前提时被消费。对 weak-FSI 而言，这还可能在初始时刻允许载荷，倾角刚产生后又立即切换为拒绝。

#### 必需修正

应使用有量纲浸没净空而不是面积分数近似等于 1 来定义 `full`。以当前正深度约定：

\[
d_c=r_i\cos\theta-h_O,
\qquad
g_{\rm sub}=d_c-R|\sin\theta|.
\]

建议分类：

```text
g_sub > clearanceTolerance    => full
|g_sub| <= clearanceTolerance => touching，拒绝 CFD
其余                         => partial 或 dry
```

对当前不含自由表面的二维单相参考，还应考虑要求一个大于零的物理净空，而不仅是刚好相切。

### F-03 Minor：有限正激活参数可产生 `NaN`

#### 位置

```text
04-P0预测链闭合修正版/src/wetting.ts:41-55
```

#### 问题

入口只要求 `activationFraction` 为有限正数，然后直接计算平方。复现结果：

```text
activationFraction = 0.05              => finite
activationFraction = 1                 => finite
activationFraction = 1e100             => finite
activationFraction = 1e200             => NaN
activationFraction = Number.MAX_VALUE  => NaN
```

#### 影响与修正

该量的语义是“无量纲湿投影分数尺度”，因此应约束：

\[
0<\lambda_a\le1.
\]

并在函数返回前硬检查结果有限。如果未来允许超出分数范围的数学尺度，需改成不会中间平方溢出的稳定计算形式。

## 6. 不是候选缺陷、但是当前验收阻断的事项

### 6.1 修正尚未对正式程序生效

这是用户原先要求“只新建文件夹、不修改原文件”的必然结果，不是 Pro 违反了当时范围。但它意味着当前正式程序仍然：

- 在 `02-模拟程序/src/solvers/forward/model.ts:103-118` 使用布尔干湿尾流开关；
- 在 `02-模拟程序/src/analysis/structure.ts:249-320` 对对称零状态直接线性化，虽报告残差，但没有对非零残差硬拒绝；
- 在 `02-模拟程序/src/solvers/highFidelity/model.ts:578-588` 不检查代表条带是否浸水就构造复制力矩；
- 正式配置 schema、GUI 表单、配置哈希和结果 provenance 不认识新 `activationFraction`、closure ID 和结构分析 ID。

因此当前 GUI 里重新运行得到的仍是原方程结果，不是 Pro 候选结果。

### 6.2 新激活函数没有物理标定

候选文档对此的表述是诚实的：`activationFraction` 是新闭合参数，不是自然常数。在没有实验或可信规定运动数值证据前：

- 可以把它当作连续数值先验；
- 不能把它当作已被验证的装置湿润—尾流物理定律；
- 不能由它直接获得实物振幅、锁频边界或增长率的定量预测资格。

### 6.3 二维完浸圆只是截面参考

即使 F-02 修正，“代表条带完全浸没”也只是消费当前二维单相完整圆载荷的必要几何前提，不是三维装置预测的充分条件。它仍然不包含：

- 自由表面变形与破波；
- 有限湿跨的端部三维效应；
- 沿跨幅的相位和相干长变化；
- 完整有限圆柱三维湿面力矩；
- 当前 Brinkman 内部虚拟流体校正和独立第二取力路径。
