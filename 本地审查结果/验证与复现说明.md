## 5. 各脚本的预期结果

### 5.1 `01-干湿起始连续性.ts`

目的：显示原布尔开关的有限跳变与候选的连续干态极限。

关键预期：

```text
theta=0:
  originalSheddingAngularFrequency = 0
  candidateSheddingAngularFrequency = 0

theta=1e-9:
  originalSheddingAngularFrequency ≈ 3.560471674
  candidateSheddingAngularFrequency ≈ 4.097494347e-20
  originalWakeRealDerivative ≈ +0.039584346
  candidateWakeRealDerivative = -0.04
```

解读：候选消除了原有有限跳变；这不等于激活函数的物理形式已被标定。

### 5.2 `02-结构适用域硬门.ts`

目的：复现 F-01。

关键预期：

```text
returnedSpectrum = true
residualNorm = 0
COEFFICIENT-OOD margin ≈ -48.8047808765
```

解读：这是当前候选的 FAIL 证据。修正后脚本应改为期望结构函数显式拒绝返回谱。

### 5.3 `03-自由液面条带边界.ts`

目的：复现 F-02。

关键预期：

```text
theta=0      => wetFraction=1, state=full, supported=true
theta=2e-12  => wetFraction=0.5, state=partial, supported=false
```

解读：共面于自由液面的截面不应被当作液体内部的完浸圆。修正后应引入 `touching/unsupported`。

### 5.4 `04-条带面积随机交叉核验.ts`

目的：验证候选一般圆弓面积公式没有符号、归一化或圆弧公式错误。

预期：

```text
samples = 100000
maximumAbsoluteError ≈ 3.33e-16
```

解读：这是 PASS 证据，不是三维水动力验证。

### 5.5 `05-激活参数有限性.ts`

目的：复现 F-03。

关键预期：

```text
activationFraction=1e200            => result=null in JSON, finite=false
activationFraction=Number.MAX_VALUE => result=null in JSON, finite=false
```

JavaScript `JSON.stringify` 会把 `NaN` 序列化为 `null`，因此脚本同时输出 `finite=false` 和 `rawResult="NaN"` 来消除歧义。

## 6. 修正后应如何转为正式回归

当 F-01、F-02、F-03 修正后，不应只保留这些手工脚本。应把它们转入候选包的 Vitest 套件，至少增加：

1. 域外 Reynolds 数不得返回谱；
2. 平衡点超过 `calibrationMaxAbsAngle` 不得返回谱；
3. 平衡点在域内但五点差分模板越域时不得静默继续；
4. `stripAxialCoordinate=pivotHeight, theta=0` 必须是 `touching/unsupported`；
5. 极小倾角不得从“允许”跳为“拒绝”而没有明确事件语义；
6. 任何通过入口校验的 `activationFraction` 都必须产生 `[0,1]` 内的有限结果。
