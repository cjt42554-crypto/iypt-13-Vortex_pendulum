## 1. 本目录已经完成的工作

### 1.1 连续干湿尾流闭合

原基线以 `projectedArea > 1e-15` 决定尾流参考速度是否从零切换到完整来流，导致刚刚沾水时尾流频率、增长率、饱和项和耦合项发生有限跳变。

候选实现改为显式湿润状态

\[
\lambda_w=\frac{A_{\perp x,w}}{D(\ell_b-\ell_t)},
\qquad
0\le\lambda_w\le1,
\]

以及满足

\[
a_w(0)=0,
\qquad a_w(1)=1
\]

的连续激活函数。尾流频率、增长、立方饱和和结构—尾流耦合随 `a_w` 连续关闭。全干分支严格满足

\[
\omega_s=\beta_r=\beta_i=\gamma_j=0,
\qquad
\dot A=-A/\tau_{w0}.
\]

实现位置：

- `src/wetting.ts`
- `src/forward/model.ts`

`activationFraction` 是新的闭合参数，不是自然常数；必须随系数包保存和标定。

### 1.2 全干分支不再误触系数域外终止

全干状态不消费水动力系数，因此候选守卫在全干分支旁路 Reynolds 数、体动比和来流变化率的水动力标定域检查。角域、实体接触、惯量正定性和数值有限性守卫仍然有效。

### 1.3 结构分析先求真实平衡

候选结构模块先解

\[
F(X_\ast;\Pi)=0,
\]

再计算

\[
D_XF(X_\ast;\Pi).
\]

非零弹簧参考角、装置偏置或其他对称性破缺时，不再把 `X=0` 的 Jacobian 解释为平衡稳定性。Newton 线搜索失败或平衡残差不达标时，谱分析直接拒绝继续。

实现位置：`src/structure/equilibrium.ts`。

### 1.4 二维 CFD 条带增加真实浸水门

当前二维后端中的数值圆柱始终是单相流体中的完整浸没圆。它不能表示穿越自由液面的圆弓湿截面。因此候选门不是只检查条带站位是否位于实体轴段，而是计算该材料截面的精确湿面积分数，并且只在截面**完全浸没**时允许使用当前二维圆柱载荷。

- 全干条带：禁止构造载荷；
- 部分浸没条带：禁止构造载荷；
- 完全浸没条带：只允许明示的代表条带复制情景；仍不是三维装置载荷。

实现位置：`src/highFidelity/strip-wetting.ts`。

### 1.5 分离模型身份

本目录区分：

1. 理论模型族；
2. 当前均匀来流、常系数、连续湿润闭合包；
3. 前向数值候选；
4. 二维截面流体参考；
5. 平衡优先的结构分析候选。

实现位置：`src/model-identity.ts`。
