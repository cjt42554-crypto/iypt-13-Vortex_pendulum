## 5. 失败、警告与处置

- 首次移植测试发现 exact-dry 阻力矩为 IEEE-754 `-0`；实现改为 exact-dry 显式返回正零，未修改测试断言。
- 安装阶段 npm 提示 `esbuild@0.28.2` 的 install script 尚未纳入 `allowScripts` 审批清单；安装和验证未因此失败。
- 原程序安装阶段提示 `glob@10.5.0` 已弃用；本轮范围禁止修改原程序依赖，因此仅记录，不在候选中越界处理。
- 未降低容差、删除测试、吞掉异常或把拒绝改成静默有限结果。
