# 整合与迁移说明

## 1. 原则

本目录不是第二份永久维护的完整程序，而是一个可审查的 P0 修订候选。只有在测试、代码审查和数值回归通过以后，才应把修改合入正式版本。合入时必须升级模型和配置身份，不能在原 `VP-FWD-P0-SL1-v1` 名称下静默改变方程。

建议正式身份：

- 理论族：`VP-FWD-P0-SL1-v1`；
- 闭合包：`VP-FWD-P0-SL1-UNI-CONST-WETCONT-v1`；
- 求解器：沿用 DOPRI5(4)，但结果 provenance 必须记录新闭合包；
- 结构分析：`VP-STRUCT-EQUILIBRIUM-LINEARIZATION-v1`；
- 二维参考：继续独立使用 `VP-CFD2D-SECTIONAL-A1-v1`。

## 2. 未来合入点

### 2.1 前向连续模型

候选源：`src/forward/model.ts`

正式合入目标：

- `02-模拟程序/src/solvers/forward/model.ts`
- `02-模拟程序/src/core/types.ts`
- `02-模拟程序/src/core/config.ts`
- `02-模拟程序/src/core/provenance.ts`

必须新增并版本化的配置参数：

```text
rom.wetActivationFraction
rom.dryToleranceWetFraction
```

不得继续将本候选中的默认数值作为隐藏常数。配置哈希、参数表单、JSON schema、默认示例和 provenance 必须同步更新。

### 2.2 前向积分器

原 DOPRI 主体可以继续复用，但要把：

- RHS；
- 守卫；
- 输出采样；
- 模型 ID；
- 系数包 ID

全部切换到同一个新版本。不得只替换 RHS 而保留旧守卫或旧 provenance。

另需补充：

1. 干→湿→干的整段事件回归；
2. 湿润分支切换时的根定位或步内最小裕度检查；
3. 相切守卫和一个接受步内双穿越的对抗性测试；
4. 24/48/96 点湿几何积分收敛；
5. `J_a'(theta)` 差分步长收敛。

### 2.3 结构分析

候选源：`src/structure/equilibrium.ts`

正式合入目标：`02-模拟程序/src/analysis/structure.ts`

新的硬门应为：

```text
先求 F(X*)=0
→ 报告平衡残差
→ 只有残差通过才线性化
→ 再进行特征值/Hurwitz/Hopf 候选判断
```

不能在求解失败时回退到 `X=0`。对于多平衡配置，应从多初值求解并去重，分别报告每个平衡及其稳定性。

### 2.4 二维条带

候选源：`src/highFidelity/strip-wetting.ts`

正式合入目标：

- `02-模拟程序/src/core/config.ts`
- `02-模拟程序/src/solvers/highFidelity/model.ts`
- `02-模拟程序/src/core/provenance.ts`

当前二维圆柱是完整浸没圆，因此强制规则是：

```text
fixed/prescribed：所选站位必须完全浸没，否则拒绝运行；
weak-fsi：每个格子步都检查站位，离开完全浸没域立即终止；
stripClosure=none：三维总力矩保持未定义；
复制情景：只在完全浸没时允许，仍标为 scenario-only。
```

以后若实现自由液面二维截面，才可以为部分浸没条带定义新的后端与新的模型 ID；不能复用当前 ID。

## 3. 验收门

P0 修订合入正式版本前，至少满足：

1. 新目录全部测试通过；
2. 原目录测试不回归；
3. 干态、极小湿段、部分湿润和全湿润 RHS 无有限跳变；
4. 全干状态不会因 Reynolds 数为零而终止；
5. 有偏置配置的结构谱只在真实平衡处计算；
6. 部分浸没二维条带被拒绝，而不是继续给出载荷；
7. 120 s 前向旧基线差异被明确归因为方程版本变化，并保存新旧并行结果；
8. README 和 GUI 不再把二维截面后端简称为整机“高保真预测”。
