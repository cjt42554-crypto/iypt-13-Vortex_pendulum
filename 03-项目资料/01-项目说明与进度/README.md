## 启动本地桌面程序

现有界面采用 Vite/TypeScript，是为了让前向求解器、二维流体后端、Web Worker、Canvas 流场和 JSON/CSV 导出共用同一份实现；它并不访问远程服务器。现在可以用独立桌面窗口启动，不显示浏览器地址栏，也不需要安装 Electron：

```bash
npm install
npm run desktop
```

程序只在随机分配的 `127.0.0.1` 回环端口提供静态资源。每次启动使用隔离的临时浏览器配置；关闭应用窗口后，本地服务和临时配置都会自动停止、清理。物理计算仍由项目内现有 worker 和两套求解器执行。

将它加入 Ubuntu 应用菜单：

```bash
npm run desktop:install
```

随后搜索“涡流摆研究平台”即可。若不再需要菜单入口，可运行 `npm run desktop:uninstall`；这两个命令只会覆盖或删除带本项目管理标记的同名入口。桌面服务的无窗口自检为 `npm run build && npm run desktop:check`。

这是一层轻量桌面外壳，仍使用本机 Chrome/Chromium 的渲染内核；不是把科学程序改写成原生控件。这样可以保留当前 GUI 和未来理论模块的可修改性，也避免额外引入一套体积较大的桌面运行时。

界面外壳、控件、状态提示和诊断图统一使用白底、黑字和中性灰辅助线；只有“运动与流场”物理场景保留语义颜色，例如蓝色水体/负涡量和橙色摆锤/正涡量。这个边界已纳入浏览器端到端测试。

## GUI 参数输入与流场显示

“运行配置”现在以可视化表单为主入口。68 个参数按几何、摆体、流体、支承、初值、运行控制以及后端专属的前向闭合或二维 CFD 分组；字段直接显示单位、参数合同上下界和用途说明。切换后端时只显示该后端实际适用的专属参数。无效、越界或非整数输入会在字段和配置状态中明确报错并阻止运行。

完整 JSON 保留在“高级：查看或编辑完整 JSON”折叠区，用于精确复现、审计和批量修改，而不再是唯一的人机输入方式。表单修改会同步写回 JSON；合法 JSON 修改、导入和恢复默认也会反向刷新表单。导出配置仍导出最终统一的 schema 3.0.0 配置，因此两种入口不会产生两份互相漂移的状态。

二维 CFD 运行期间，GUI 缓存最近一个完整流场帧；只有时间样本而没有新场帧的 worker 消息继续复用该帧，不再退回前向尾流示意图。画布模式在一次二维截面运行中只允许 `waiting-cfd → cfd`，完成后仍停留在本次 CFD 结果。

## 运行二维截面流体参考后端

默认运行固定二维圆柱，原生载荷单位为 N/m，不会伪装成三维装置总力：

```bash
npm run simulate:high-fidelity -- \
  --duration 0.5 \
  --output ../03-项目资料/03-计算结果与证据/artifacts/high-fidelity-smoke.json \
  --csv ../03-项目资料/03-计算结果与证据/artifacts/high-fidelity-smoke.csv
```

该后端求解 D2Q9 MRT–Brinkman 二维低 Mach 流场。A1 输出的是本步实际 Guo source 的 raw 反力冲量与功账本，尚未做虚拟内部流体修正，不是已验证物理水动力；更不是三维自由表面 DNS。

GUI 顶部明示五类合同徽标：维度层级、载荷定义、耦合算法、跨度闭合和证据等级。位移叠图会核对共享物理输入哈希、观测位置、时间区间和动力学合同；ROM 端口功与 CFD raw 功语义不兼容，不会在功率面板中当作同一量叠加。

## 验证

```bash
npm run validate
npm run audit:forward-convergence
npm run audit:high-fidelity   # 历史核心/组件审计，不升级动态取力证据
npm run analyze:high-fidelity-grid
npm run analyze:structure
npm run analyze:cross-layer
npm run plot:structure
```

默认配置使用文献先验系数，只用于可执行机制研究和数值验证，不代表尚未标定装置的定量预测。

第四阶段已经严格区分固定体尾流 Hopf、全耦合稳态谱边界、有限时间可见面、复功率零面、1:1 锁频边界与周期轨道分支。跨层研究实际调用前向程序完成 6 条 300 s 冷热启动，并调用二维后端完成 9 条规定运动响应；它们揭示了临界减速、观测阈值位移、相位功率病态和双频竞争，但仍分别属于未标定先验与未收敛二维证据。当前没有装置专属系数、已收敛三维载荷、周期延拓/Floquet 或实验盲测，因此不得报告实物临界流速、锁频舌或定量振幅图。
