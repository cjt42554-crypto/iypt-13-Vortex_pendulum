## 五、代码中的力学、ROM 与二维闭合

共享机械方程与能量约定为

```text
I_eff(theta) theta_ddot + 0.5 I_a'(theta) theta_dot^2
  = Q_fluid + Q_buoyancy + Q_gravity + Q_elastic + Q_axis

P_fluid = Q_fluid theta_dot
P_damping >= 0
dE_mech/dt = P_fluid + P_control - P_damping
```

前向 ROM 为

```text
A_dot = (mu + i omega_s) A - (beta_r + i beta_i)|A|^2 A
        + gamma_0 theta + gamma_1 theta_dot + gamma_2 theta_ddot

C_L = finiteSpanCoherence * Re(L A)
Q_fluid = Q_lift + Q_drag
Q_drag = -0.5 rho C_D theta_dot
         * integrateWetProjection[r^2 sqrt(U^2 + (r theta_dot)^2)]
```

默认 ROM 关键值：`C_A=1`、`C_D=1.2`、`St=0.2`、有限跨相干因子 `0.65`、`L=(1.2,0)`；`gamma_1=(0.10,0)`、`gamma_2=(0.08,0)`，所有列出的虚部为零。请特别审查：这些相位选择是否在当前坐标/输出约定下把流体能量通道锁成了不正确的相位；阻力闭合是否与真实摆式圆柱的顺流/横流投影一致；是否遗漏或重复计算某个流体惯性/阻尼通道。

这里的 “D/12 默认” 只指沿用 GUI 的默认网格与数值参数；项目出厂 `DEFAULT_CONFIG` 实际是 `couplingMode=fixed, stripClosure=none`。本次比较按用户明确选择把它改为 `weak-fsi + fully-coherent-upper-bound`，这两项不是无意的默认值。

二维弱耦合 FSI 中

```text
y_c = y_0 + r_strip sin(theta)
v_c,y = r_strip cos(theta) theta_dot

Q_CFD = F'_y cos(theta) / D
        * integrateWetProjection[r]
```

其中 `F'_y` 是二维截面的单位跨长力 `[N/m]`，默认 `r_strip=0.13 m`；`Q_CFD` 是把同一个截面线力完全相干地复制到湿跨所得的上界。机械更新是每个格子步一次的显式/辛式弱耦合，没有 FSI 子迭代；CFD 力已隐含流体惯性，所以调用共享机械模块时显式令附加质量系数为零。

## 七、已做的区分性检查及仍未关闭的数值门

1. **近静水控制**：保持同一物理—格子映射，但把来流爬升时间设为 `1e9 s`，6 s 内实际来流近零。振幅衰减，惩罚与应力两路径平均功率都为负。这不支持“CFD 全局力符号写反”这一最简单假设。
2. **低 Mach**：把格子来流速度由 `0.05` 降至 `0.025`；峰值 Mach 从约 `0.171` 降至 `0.0769`，密度偏差从 `0.0558` 降至 `0.0102`，增长没有消失。因此默认增长不是只由高 Mach 可压缩误差解释；但力路径差仍很大。
3. **网格与网格相位**：D/12、D/16 和替代 grid phase 均增长，D/8 近中性。符号在较细两个网格上保持，增长率却不收敛。
4. **固定圆柱网格研究**：`D/8,D/12,D/16` 的固定圆柱 `St` 约 `0.16195,0.16399,0.17018`；升力 RMS 与 Strouhal 不是单调渐近序列，细网格两条取力路径仍相差至少约 15%，结论正式标为 `INCONCLUSIVE`。
5. **ROM Strouhal 扫描**：把 `St` 从 `0.20` 扫到 `0.16–0.19`，升力平均功率有时转正，但总流体功率始终约 `-3.52e-8` 到 `-4.08e-8 W`；只改 `St` 不足以翻转总趋势。
6. **ROM 初始尾流相位**：初始复幅值固定为 `1e-3`，相位取 `0,pi/2,pi,3pi/2`，总流体功率仍全部约 `-4.07e-8` 到 `-4.11e-8 W`。
7. **ROM 长运行**：既有 240 s 运行在 192–240 s 的位移幅值仅 `1.3669e-4 m`；平均流体功率 `1.8343e-10 W`、阻尼 `1.7062e-10 W`，只是形成极小平衡响应。12 s 衰减并非唯一由尚未饱和的初始尾流暂态解释。
8. **能量离散闭合**：默认 ROM 的能量闭合相对 RMS 为 `1.95e-4`；D/12 弱耦合 CFD 为 `6.70e-2`，D/8–D/16 约 `6.4%–8.0%`。请判断这种残差是否足以污染当前增长率，以及应采用何种离散功交换/子迭代才能做可信 FSI 能量判定。
