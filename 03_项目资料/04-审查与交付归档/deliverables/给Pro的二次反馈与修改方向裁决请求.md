## 2. 已由本地源码和原始数据再次确认的发现

### 2.1 已确认：应力圆周积分存在确定性的弧长半径错误

当前源码 `src/solvers/highFidelity/lbm.ts:582–607` 为：

```ts
const sampleRadius = body.radius + this.maskHalfThickness + 0.75;
const ds = 2 * Math.PI * body.radius / count;
```

应力在 `sampleRadius` 圆周采样，却使用 `body.radius` 计算弧元。对当前三套网格，代码弧长相对采样圈弧长的比例为：

| 分辨率 | `body.radius` | `sampleRadius` | 当前 `ds` / 采样圈正确 `ds` |
|---|---:|---:|---:|
| D/8 | 4 | 5.5 | `0.7272727` |
| D/12 | 6 | 7.5 | `0.8000000` |
| D/16 | 8 | 9.5 | `0.8421053` |

我们接受：当前 penalty/stress 差异中含有确定性、且随网格变化的诊断公式偏差。

我们也接受更重要的判断：**仅把 `ds` 改成基于 `sampleRadius` 仍不足以修复取力。** 外控制圈上的应力积分若要等价于固体受力，还需要与控制体内流体动量库存、对流动量通量和移动边界输运项形成完整动量平衡。

因此，原项目不得继续把当前 stress contour 称为“独立固体取力路径已经验证”。

### 2.2 已确认：weak-FSI 的实际施力与事后报告功率不在同一时间层

当前 `src/solvers/highFidelity/model.ts:243–279` 的实际顺序为：

1. 由当前流场和当前结构状态计算 `reaction`；
2. 将 `reaction` 映射成结构力矩；
3. 用该力矩计算结构加速度；
4. 用旧刚体位置/速度推进一次流体；
5. 更新 `omega`；
6. 更新 `theta`；
7. 用推进后的流场与新结构状态重新 `inspect`；
8. `makeSample()` 使用新的诊断力和新 `omega` 计算 `fluidPower`。

所以当前输出中的

```text
fluidPower = diagnosticTorque_after_step * omega_after_step
```

不是本步实际施加给结构的界面功。

此外，虽然代码写有：

```ts
const midpoint = this.time + 0.5 * this.mapping.dt;
const body = this.bodyAt(midpoint);
```

但 `weak-fsi` 分支的 `motionAt(time)` 不使用 `time`，只返回当前保存的 `thetaState/omegaState`。名义“半步”仍是旧结构状态。

我们接受：当前算法不是功一致中点方法，也不是强耦合 FSI；推进力、诊断力和功率必须分开存储。

### 2.3 已确认：D/12 的平均正功不能由 6.7% RMS 指标直接解释

我们重新从归档中的 D/12 原始 CSV 计算 6–12 s 机械能变化率：

```text
(E(12 s)-E(6 s))/6 s
= 9.08861015445414e-8 W
```

机器汇总中的梯形平均净机械功率为：

```text
mean(P_fluid-P_damping)
= 9.122972959176723e-8 W
```

平均差约：

```text
3.4363e-10 W
```

只占净正功约 `0.377%`。因此我们接受：

- `energyClosureRelativeRms≈0.067` 不能被直接解释成“D/12 的全部正功是结构侧记账误差”；
- 当前离散结构系统确实产生了正机械能增长；
- 但结构侧记账闭合不能证明输入水动力正确，错误水动力同样可以被结构方程忠实地转化成机械能增长；
- D/8 的净功极小，误差与净功更接近同量级，D/8 的符号不应被用于判断起振边界。

### 2.4 已接受：默认 ROM 不是只改相位即可修复

第一轮审查估算当前 ROM 的准稳态流体等效阻尼约为：

```text
c_D ≈ 1.118e-4 N·m·s/rad
```

约为轴阻尼 `3.0e-5 N·m·s/rad` 的 `3.73` 倍。

6–12 s 的阻力和轴损失约为：

```text
|mean(P_drag)| + mean(P_axis)
≈ 4.83e-8 W
```

按当前升力幅值，即使把相位旋转到最有利位置，最大正功仍仅约 `2.71e-9 W`，低约 18 倍。

因此我们接受：默认 ROM 的问题至少同时涉及：

- 尾流输出增益；
- 运动—尾流反馈增益；
- 复输出和复耦合相位；
- 准稳态阻力闭合；
- 跨度幅值/相干闭合；
- 可能的单复模模型结构不足。

初始尾流相位扫描只能说明“不是某一个初始相位导致 12 s 负功”，不能验证 `L`、`gamma_j` 和尾流状态规范所决定的传递函数相位。

### 2.5 已接受：“完全相干上界”不是严格的装置功率上界

当前代码实质上令：

```text
F'_y(r,t) = F'_y(r_strip,t)
```

再复制到整个湿跨。这不仅假定全部截面同相，还假定：

- 力幅相同；
- 非线性响应相同；
- 不同 `r` 处虽然运动幅值 `r*theta` 不同，仍共享同一个代表截面力；
- 自由表面、端部、局部湿宽和三维失相干不改变力幅相。

因此我们倾向于把名称降级为：

```text
coherent representative-strip replication scenario
完全相干代表条带复制情景
```

而不再称其为未经限定的“真实三维上界”。

第一轮给出的冻结轨迹局部估算：

```text
c_crit ≈ P_axis/P_CFD ≈ 0.169
```

可以保留为“当前结果对跨度缩放非常敏感”的局部诊断，但不能称为自洽分岔阈值；因为改变跨度因子以后，轨迹、尾流相位和平均功都会改变。
