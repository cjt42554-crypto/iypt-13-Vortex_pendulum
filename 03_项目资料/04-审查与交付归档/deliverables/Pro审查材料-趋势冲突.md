## 0. 先读结论边界

当前可以由机器结果直接支持的是：

1. 这不是单纯的 GUI 画线问题。默认前向 ROM 与本次 D/12 弱耦合 CFD 的共享物理输入哈希一致，原始时间序列确实分别衰减和增长。
2. 分歧的直接动力学原因是**周期平均流体机械功符号相反**：ROM 在 6–12 s 给负流体功，二维 CFD 的惩罚反力和应力圆周积分两条路径都给正流体功。
3. 最简单的“CFD 力全局翻号”假设不符合近静水控制；默认高 Mach 也不是增长存在的唯一原因。可是，CFD 的载荷量值、能量交换和网格趋势仍未达到可接受收敛门。
4. 前向程序的积分误差很小，但默认尾流、升力、阻力和有限跨度系数只是未标定文献先验。因此“程序忠实求解了当前 ROM”不能升级为“ROM 正确预测了装置”。
5. 目前不能从这两条曲线中选出真实实验答案。严格说，两者都只能形成待实验/更高层验证的候选：ROM 很可能低估或错置流体正功通道；二维完全相干上界很可能高估正功并受弱耦合离散影响。

本包邀请 Pro 审查上述第 2–5 点，而不是要求接受它们为最终结论。

## 2. 官方范围与本项目研究者选择

### 2.1 官方事实

题目是 hydrodynamic **Vortex pendulum**，不是电磁“涡流制动摆”。官方最小信息是：圆柱摆锤竖直取向、部分浸水、通道来流、横流方向可能发生振荡，并要求研究相关参数依赖。官方材料没有冻结圆柱尺寸、悬挂拓扑、是否全过程保持竖直、摆长、流速、阻尼或 Reynolds 数。

官方来源、最终 PDF、题图指纹和一手文献证据矩阵见 `research-notes/R1-official-and-primary-evidence.md`。

### 2.2 canonical P0 是研究者选择

本项目选择：

- 固定转轴与来流平行；
- 圆柱—摆臂刚性连接；
- 只保留横流平面内转角 `theta`；
- 零角时圆柱轴线竖直，摆动时圆柱随刚体倾斜；
- 平水面几何，允许湿长随角度变化；
- 圆柱有限半径，不用无厚度细杆替代；
- 观测量为实体标记处 `x_obs=r_obs sin(theta)`，观测力臂不自动等于水动力力臂。

这与一种可操作的旋转圆柱摆研究类同构，但不是官方唯一装置。若真实实验使用四杆机构使圆柱始终竖直、柔线球摆或其他自由度，当前两个后端都会发生结构性模型错配。

## 3. 四层材料严格分开

### 3.1 第一层：前向预测理论

规范文档：`theory/forward-theory.md`。执行模型 ID：`VP-FWD-P0-SL1-v1`。

状态向量为

```text
X = (theta, omega, A_R, A_I),  omega = theta_dot,  A=A_R+i A_I.
```

共享机械模块写成

```text
I_eff(theta) theta_ddot + 0.5 I_a'(theta) omega^2
 = Q_dyn + Q_B + Q_g + Q_k + Q_axis,

I_eff = I_dry + I_a(theta).
```

代码中 `Q_B` 来自精确有限圆柱平水面湿几何，`Q_g` 是质量重力矩，`Q_k` 是扭簧，`Q_axis` 含黏性与平滑库仑摩擦。附加惯量候选为

```text
I_a(theta) = C_A rho * wet axial second moment.
```

复 Stuart–Landau 尾流为

```text
A_dot = (mu+i omega_s)A -(beta_r+i beta_i)|A|^2 A
        + gamma_0 theta + gamma_1 omega + gamma_2 theta_ddot.
```

代码中的升阻力矩为

```text
C_L = kappa * (L_R A_R - L_I A_I)

Q_L = 0.5 rho U^2 C_L
      * integrateWetProjection[r U/sqrt(U^2+(r omega)^2)]

Q_D = -0.5 rho C_D omega
      * integrateWetProjection[r^2 sqrt(U^2+(r omega)^2)]

Q_dyn = Q_L + Q_D.
```

默认系数不是装置辨识值：

| 参数 | 默认值 | 证据状态 |
|---|---:|---|
| `coefficientSetId` | `illustrative-literature-prior-v1` | 名称即声明为示意先验 |
| `coefficientSource` | `literature-prior` | 未由本装置校准 |
| `C_A` | `1` | 势流候选 |
| `C_D` | `1.2` | 准稳态候选 |
| `St` | `0.2` | 固定圆柱先验；本 CFD 固定体结果约 0.162–0.170 |
| `finiteSpanCoherence` | `0.65` | 未标定 |
| `L_R,L_I` | `1.2,0` | 输出相位未标定 |
| `gamma_1` | `0.10+0i` | 运动—尾流耦合先验 |
| `gamma_2` | `0.08+0i` | 加速度—尾流耦合先验 |
| 其余列出的耦合虚部 | `0` | 未经过相位辨识 |

第一层的关键待审查点不是积分器，而是：单复模是否足够、输出与运动耦合的相位约定、准稳态阻力广义投影、正功/负功通道如何辨识，以及有限湿跨与自由表面是否可用一个常数相干因子替代。

### 3.2 第二层：前向数值计算理论与程序

规范文档：`theory/forward-numerical-theory.md`。源码：`src/solvers/forward/`。

- 连续右端与积分器分离；

- 四状态分别有绝对容差，另有相对容差；
- 在输出时间点插值/落点，带角度、接触、惯量正定、系数出域和非有限状态事件；
- 能量记账使用

```text
dE_mech/dt = P_fluid + P_control - P_damping.
```

| 数值量 | 值 |
|---|---:|
| 终止 | `COMPLETED` |
| 方法 | Dormand–Prince 5(4) |
| 主频 | `0.5036943 Hz` |

### 3.3 第三层：二维 CFD/弱耦合 FSI 参考程序

规范文档：`theory/high-fidelity-simulation.md`。源码：`src/solvers/highFidelity/`。

实际能力必须按以下边界理解：

| 项目 | 当前实现 |
|---|---|
| 空间维数 | 二维截面、无限展向 |
| 方程极限 | 单相、等温、低 Mach Navier–Stokes 的 LBM 近似 |
| 离散 | D2Q9 MRT + Guo forcing + 弥散 Brinkman 圆柱 |
| 外边界 | 流向 Zou–He 定速入口 / 定密度出口；横向周期 |
| 自由表面 | 无 |
| 有限湿跨端部 | 无 |
| 三维 Mode A/B、跨向失相干 | 无 |
| 原生载荷 | 单位跨长线力 `[N/m]` 与线功率 `[W/m]` |
| 弱 FSI | 每格子步显式/辛式更新，无子迭代 |
| 从二维到总力矩 | 完全相干湿跨上界，不是三维预测 |
| 当前证据等级 | `verified-component`, `reference-only` |

物理—格子映射：

```text
dx = D / N_D
dt ≈ u_lattice dx / U
lineForceScale = rho dx^3/dt^2.
```

弱耦合时，代表截面位于 `r_strip=0.13 m`：

```text
y_c = y_0 + r_strip sin(theta)
v_c,y = r_strip cos(theta) omega.
```

LBM 内 Brinkman 体力是施加给流体的力密度；程序对其全域求负和得到固体反力。应力路径在圆柱外侧一圈积分 `sigma n_body`。二者都被当作流体对固体的二维线力。这个符号解释看起来内部一致，但仍应由独立审稿者从控制体与虚功重新推导，不能仅凭两条实现同号就算通过。

完全相干上界为

```text
Q_CFD = F'_y * cos(theta)
        * integrateWetProjection[r] / D.
```

单位核对：`F'_y [N/m]`，投影一阶矩 `[m^3]`，除以截面宽度 `D [m]`，得到总力矩 `[N m]`。这相当于让一个代表二维截面的线力系数在整个湿跨同相、同幅；它会保留瞬时功率符号，却可能把正功幅度放大到超过结构阻尼而形成假自激。

弱耦合步序在 `src/solvers/highFidelity/model.ts` 中是：

1. 用当前流场分布、半步时刻的刚体位置/速度计算 Brinkman 反力；
2. 映射为总力矩，计算结构加速度；
3. 用同一半步刚体状态推进一次流体；
4. `omega += acceleration*dt`；
5. `theta += omega*dt`。

没有强耦合迭代，也没有显式保证界面功 `F·v` 在流体和结构两侧离散相消。6–8% 的能量闭合残差可能来自输出差分、弥散边界和弱耦合等多项，必须在把增长当物理前分解。

### 3.4 第四层：结构性理论

规范文档：`theory/structural-theory.md`。它把系统组织为：

- 机械/湿几何骨架；
- 流体能量输入与阻尼竞争；
- 尾流失稳、锁频、有限时间可见性和分支；
- 模型层级与适用域升级；
- 可证伪预测和实验闭环。

现有结构性材料已经明确写出：ROM 系数包未标定；固定圆柱 CFD 网格结果不收敛；规定运动 CFD 的功率相位对频率/网格相位敏感；240 s ROM 只出现很小响应。因此，结构性理论不能用一条 D/12 弱 FSI 曲线把二维求解器提升为装置真值，也不能用数值误差很小的 ROM 曲线把未标定先验提升为预测。

## 6. 区分性检查的含义

### 6.1 近静水控制能排除什么

控制保持名义 `U=0.017 m/s` 以维持相同格子映射，但将 `flowRampTime=1e9 s`，所以 6 s 内实际入口近零。结果：振幅衰减，penalty/stress 两路径均取负平均功。

它支持：

- 圆柱在静水中运动时，当前反力方向大体表现为阻尼；
- 不是任意运动都会被 CFD 无条件注入正功。

它不能排除：

- 来流存在时的压力/升力符号错误；
- 出口反射或周期横向边界改变相位；
- 显式弱耦合在有强尾流反馈时产生正数值功；
- 代表条带到总湿跨映射过强。

近静水中力很小时，相对取力差的分母病态，因此该控制的相对差最大值不能当主要量值指标。

### 6.2 低 Mach 检查能排除什么

把目标格子速度从 `0.05` 降到 `0.025`，峰值 Mach 降到 `0.0769`、密度偏差约 `1%`；增长未消失。

它降低“增长纯粹是默认 Mach 太高”的可信度，但没有做严格 Mach² 序列外推，也没有同时关闭 Brinkman 参数、网格和 FSI 时间步耦合。低 Mach 结果的增长反而更大，说明需要审查“为保持物理 Re 而改变 dt/tau/penalty 后，界面阻抗如何变化”，不能只看 Mach 数。

### 6.3 网格检查能排除什么

D/12 与 D/16 增长、D/8 近中性；替代 grid phase 仍增长。可说：默认增长不是单个 seed 或最粗/单一网格的偶然。不能说：增长率已收敛。D/8 的近中性正说明起振边界与数值分辨率耦合显著。

### 6.4 ROM `St` 与初始相位检查

`evidence/generated/forward-trend-sensitivity.json` 显示：

| `St` | 升力平均功率 W | 阻力平均功率 W | 流体总功率 W |
|---:|---:|---:|---:|
| 0.16 | `+1.2385e-9` | `-3.8692e-8` | `-3.7453e-8` |
| 0.17 | `+3.6285e-9` | `-3.8854e-8` | `-3.5225e-8` |
| 0.18 | `+2.7006e-9` | `-3.8778e-8` | `-3.6077e-8` |
| 0.19 | `-1.0719e-9` | `-3.8475e-8` | `-3.9547e-8` |
| 0.20 | `-2.5865e-9` | `-3.8239e-8` | `-4.0825e-8` |

把 `St` 调到 CFD 固定体范围只让升力小幅正功，不能克服阻力负功。初始复尾流相位旋转四分之一周期也不翻转总功率。这提示关键不是一个初始相位或 `St` 单参数，而是尾流输出相位、运动反馈增益、准稳态阻力以及幅值标度的组合。

## 7. 当前最重要的竞争假设

以下是审查假设，不是已证明归因。

### H1：ROM 流体能量相位/增益闭合错误

支持迹象：

- 默认系数未标定，且输出与耦合虚部全部为零；
- `St` 与固定体 CFD 有偏差，但单改 `St` 不解决；
- 升力通道几乎不供能，阻力强烈耗能；
- 经典 VIV 自激依赖力与速度的相位，未标定相位最可能直接改变平均功率符号。

反证需求：用规定运动 CFD 或实验在相同振幅/频率下测得一阶流体阻抗，辨识 `Q` 对 `theta/omega/theta_ddot` 的复增益，再做留出预测。

### H2：二维完全相干湿跨上界把正功放大过头

支持迹象：

- 同一个二维截面被复制到所有湿跨，忽略自由表面削相干、端部和三维模态；
- 正比例放大虽不翻转流体功符号，却能把 `P_fluid-P_damping` 从负/近零推成正，从而跨过起振阈值；
- 真实湿跨相干因子未知，ROM 另取了 0.65，两者并非同一流体模型。

反证需求：多站位二维/三维或实验相关长度，至少给相干积分而非单截面上界。

### H3：弱耦合/弥散边界产生正数值功或错误阻抗

支持迹象：

- 无 FSI 子迭代，流体和结构功交换不保证离散相消；
- 机械能量闭合相对 RMS 约 6–8%；
- penalty/stress 载荷量值差大；
- D/8 接近中性，增长率随网格和低 Mach 设置明显变化。

反证需求：强耦合或功一致中点交换；固定同一物理 `dt` 的细化；界面功双边对账；规定运动阻抗在网格/Mach/惩罚/域序列上收敛。

### H4：LBM 反力、应力法向或线力到广义力的共同符号/坐标错误

支持迹象：两条 CFD 路径共享 `y/theta` 和条带映射，可能共同错。

削弱迹象：近静水控制表现为阻尼；代码中 Brinkman 力对流体取负作为固体反力，应力使用 `sigma n_body`，表面上相容；规定运动组件测试包含功率恒等式，但只检验程序内部恒等，不是外部解析真值。

反证需求：解析 Stokes/振荡圆柱极限、运动/来流/坐标镜像测试、控制体动量通量闭合以及独立手算一个时间点的虚功。

### H5：两后端的附加质量/流体惯性对比不一致导致频率与相位差

ROM 显式取 `C_A=1`；CFD 调共享机械模块时显式 `C_A=0`，因为流场应隐含流体惯性。这避免了明显的双计数，但是否完整取决于二维弥散圆柱实际产生的惯性阻抗。若 CFD 的隐含附加质量尚未收敛，机械频率和尾流相位会漂移，进而影响平均功率。

反证需求：静水规定加速度/自由衰减下独立辨识 CFD 附加惯量与流体阻尼，并与 ROM `I_a(theta)` 在同一几何投影下对账。

## 8. 为什么当前不能回答“谁更接近实验”

没有任何本装置原始实验数据、标定文件、重复运行或观测不确定度。两个后端又有相反但各自严重的证据边界：

| 维度 | 前向 ROM | 二维弱 FSI |
|---|---|---|
| 方程求解误差 | 小，已有收敛/能量检查 | 时间/网格/边界/耦合尚未关闭 |
| 流体模型 | 极强降阶、单模、经验系数 | 更直接解析二维尾流，但不是三维/自由表面 |
| 装置参数标定 | 默认系数未标定 | 物性/几何较直接，但条带相干与边界是研究者闭合 |
| 功率可信度 | 内部能量记账好，物理相位未知 | 两取力同号，量值差大且界面功残差较大 |
| 真实有限湿跨 | 用常数 0.65 | 用完全相干上界 1.0 |
| 可作为实验真值？ | 否 | 否 |

合理但仍是条件性推断：二维 CFD 比 ROM 更直接解析 `Re≈102` 的二维脱涡，因而它提示“当前 ROM 可能漏掉正功相位”有研究价值；然而其完全相干上界和弱耦合足以制造或夸大自激，所以不能把“增长”当实验预测。真正的仲裁者应是同一装置的相位/功率实验，或至少是经过规定运动阻抗、强耦合、网格/Mach/域收敛的更可信 CFD 层。

## 9. 最小判别测试矩阵

| 优先级 | 测试 | 主要观测 | 若通过/出现的含义 |
|---|---|---|---|
