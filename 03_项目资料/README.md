# 项目资料成熟基线

本目录保存已经接受的项目说明、研究过程资料、计算结果、审查材料和历史归档。它不用于存放尚未验收的活动候选。

## 现有分类

1. [`01-项目说明与进度/`](01-项目说明与进度/)：项目范围、进度和交付导航。
2. [`02-研究过程资料/`](02-研究过程资料/)：题目、文献、建模、实验和开发过程资料。
3. [`03-计算结果与证据/`](03-计算结果与证据/)：计算结果、数值证据和可复现材料。
4. [`04-审查与交付归档/`](04-审查与交付归档/)：审查、复现和交付归档。
5. [`05-历史截图/`](05-历史截图/)：历史图像与界面记录。
6. [`资料分类说明.md`](资料分类说明.md)：既有资料分类说明。

## 资料契约

- 原始数据、处理后数据、配置、脚本、结果和结论应保持可追踪关系。
- 历史冻结证据保留其生成时路径和身份，不通过批量改写制造新的证据身份。
- 活动候选的管理记录与新证据先进入 [`../90_候选工作区/current/`](../90_候选工作区/current/)；被接受后再按类别归档到本目录。
- 当前状态见 [`../00_项目控制/STATUS.md`](../00_项目控制/STATUS.md)。
