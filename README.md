# IYPT 2027 第 13 题：涡流摆

本仓库研究 IYPT 2027 第 13 题 **Vortex pendulum**：有限尺寸圆柱摆部分浸入来流中，刚体横流运动与尾流涡脱落相互耦合。准稳态阻力通常耗散机械能，而非定常尾流载荷可以向摆输入或从摆吸收能量，因此系统可能出现振幅衰减、振幅增长、极限环、锁频、共振和分岔。

项目目标不是只拟合一条摆角曲线，而是建立从装置几何、质量与惯量、支承、来流、流体物性、水动力闭合和完整初态到摆体—尾流联合状态的可计算前向映射，并对能量传递的符号、来源和适用域进行明确记账。

## 研究内容

仓库按相互区分但可交叉核验的层次组织：

1. **前向预测理论**：建立刚体单自由度动力学、精确平水面浸没几何、静水力、加入惯量、准稳态阻力和尾流模态的耦合模型。
2. **前向理论的数值实现**：求解摆角、角速度和尾流复模态，并计算湿跨、水动力矩、功率及域状态。
3. **高保真流体模拟**：使用更完整的流固耦合模型审查降阶载荷、相位、二维/三维效应和能量收支。
4. **结构性研究**：研究振幅增长或衰减、锁频、共振舌、极限环、稳定性和分岔。

当前前向模型标识为 `VP-FWD-P0-SL1-v1`：

- `P0` 表示固定水平主轴、顺流主轴、横流单自由度的刚性圆柱摆拓扑；
- `SL1` 表示用一个复尾流模态描述占优的一级反对称涡脱落结构。

详细方程见 [`01_最终理论/01-前向预测理论.md`](01_最终理论/01-前向预测理论.md)。

## 前向预测理论采用的物理假设

以下假设是当前模型为了把开放题转化为闭合初值问题而作出的选择，并非 IYPT 题面额外规定，也不代表所有“涡流摆”装置都属于同一模型。保持圆柱竖直平移的摆、球摆、柔索摆、多自由度悬挂或不同主轴方向都需要重新建立动力学。

### 一、装置拓扑与自由度

- 圆柱在参考平衡位置轴线竖直。
- 主轴固定、水平，并与平均来流方向平行。
- 整个刚性总成只绕该主轴转动，机械状态由摆角 \(	heta\) 和角速度 \(\omega\) 描述。
- 不包含主轴平移、圆柱自转、扭摆、球面摆动、柔性摆臂或支架振动等额外自由度。
- 圆柱、摆臂、夹具和配重可共同贡献总质量、质心和绕真实主轴的干结构惯量，但这些量必须作为同一刚性总成测量或计算。
- 总成在预测区间内保持刚性，不发生实体接触、止挡碰撞、支承拓扑切换或机械松脱。

### 二、进水实体与浸没几何

- 基线模型中，只有封闭的有限半径圆柱进水、排液并接受水动力载荷；摆臂、夹具和配重保持干燥。
- 圆柱被视为平端、刚性、有限半径的实心几何体，而不是零半径线段或全长具有同一横流速度的平移体。
- 不同轴向站位到主轴距离不同，因此局部横流速度为 \(r\omega\)，必须沿湿跨积分水动力矩。
- 平均自由表面取固定平面 \(z=\eta_0\)。当前模型用圆柱与该平面的精确几何交集计算湿面积、湿投影宽度、排水体积和静水势。
- 动态自由表面、波面爬升、破波和接触线运动不作为独立状态求解；它们只有在已经辨识的闭合函数中才可间接进入。
- 干燥、部分浸没和全浸没分支共享同一几何定义。水线跨越圆柱截面边缘时不重置状态，也不施加人工冲量。

### 三、刚体恢复力与机械耗散

- 重力、线性弹簧和可选扭转弹簧通过势能进入方程，弹簧力臂随真实几何变化，不用常数“小角等效刚度”替代完整几何。
- 静水浮力通过浸没实体的势能及其角度导数进入，只计算一次；不能在经验水动力载荷中再重复加入静水恢复力。
- 轴承和机械支承耗散由角度相关的黏性阻尼与平滑库仑摩擦表示。
- 外部控制、制动或驱动力矩可以作为已知输入加入，但必须明确其功率符号和时间/状态依赖。
- 当前模型不包含机械间隙、碰撞、干摩擦粘滑的不连续事件或支承结构的弹性模态；若这些效应显著，需要使用非光滑或多自由度机械模型。

### 四、来流与流体物性

- 流体由密度 \(ho\)、运动黏度 \(
u\)、重力 \(g\) 和表面张力 \(\sigma\) 表示，在当前工况内视为已知。
- 外缘来流 \(U_e(r,t)\) 是未受圆柱自身扰动的规定顺流速度，可随湿跨位置和时间变化。
- 当前前向模型不同时求解完整水槽流场；来流是外部输入，圆柱对上游流场的全局反作用只通过已校准的水动力闭合体现。
- 平均来流方向与主轴平行，主要机械响应沿横流方向。若存在显著横向均流、主轴偏斜或左右不对称，必须把它们作为显式输入或采用新的模型。
- 水槽宽度、水深、端隙、粗糙度等通过无量纲参数进入闭合函数，不能把无限域圆柱的通用系数直接视为有限水槽、部分浸没装置的精确常数。

### 五、水动力分拆假设

当前模型把真实湿面牵引产生的总水动力矩分拆为四类：

1. **静水作用**：由平水面浸没几何和静水势给出。
2. **加入惯量**：用配置相关的加入转动惯量 \(J_a(\theta)\) 表示已从流体牵引中分离出的惯性部分。
3. **准稳态阻力**：按每个湿站位的局部相对速度、湿投影宽度和阻力系数 \(C_D\) 积分。
4. **非定常尾流载荷**：由复尾流模态产生升力和可选直接截面力矩。

这是一种唯一记账约定。若高保真流体牵引已经包含静水、非定常惯性、阻力和尾流效应，就必须重新定义分拆并删除相应低阶项，不能把两套载荷直接相加。

准稳态阻力被要求满足 \(Q_D\omega\le0\)，即它不能在当前符号约定下凭空向机械端持续注能。平均流向摆输入能量的可能性由尾流载荷承担。

### 六、单复尾流模态假设

- 当前 `SL1` 闭合假设目标工况内存在一个占优的、反对称的尾流 Hopf 模态，并且它与其他模态之间有可分辨的谱隙。
- 尾流状态由一个复振幅 \(A=A_R+iA_I\) 表示，采用带线性增长/衰减、固有频率、立方饱和和非线性频移的 Stuart–Landau 型方程。
- 摆体位移、速度和加速度可以通过已标定的复耦合系数驱动尾流；尾流再通过有限湿跨复相干函数产生升力和力矩。
- 有限湿跨不同站位的幅值和相位被约化为同一个全局模态乘以 \(\chi_L(r;\boldsymbol\Pi)\) 或 \(\chi_M(r;\boldsymbol\Pi)\)。若实测跨距结构不能这样分离，单模态闭合被否定。
- 尾流系数、耦合系数和复输出函数依赖 \(Re\)、\(Fr\)、\(We\)、湿跨比、阻塞比、端隙、粗糙度和运动幅值等工况，必须在联合标定域内给出。
- 单复模态是低阶闭合，不是 Navier–Stokes 方程的另一名称。几何和水的物性不足以从零唯一推出全部尾流参数。
- 初始尾流状态必须明确给定，不使用隐藏随机噪声启动振荡。

### 七、加入惯量与自由表面假设

- 配置相关加入惯量 \(J_a(\theta)\) 只有在它已从瞬时流体牵引中独立辨识时才使用。
- 总惯量 \(J=I_O+J_a\) 必须保持正且高于预先规定下界；配置依赖加入惯量对应的 \(J'(\theta)\omega^2/2\) 项不能省略。
- 平均自由表面被当作平面，因此模型不直接解析动态水面、表面波、局部爬升、通气或夹气。
- 表面张力仍作为工况参数进入 \(We\) 和闭合函数，但不等同于显式求解自由表面。
- 若动态自由表面与尾流或摆体运动强耦合，必须升级为含自由表面状态的模型。

### 八、定量适用条件

装置级定量预测要求同时满足：

- 装置确实属于 P0 拓扑，主轴固定并与平均来流平行；
- 总成可视为刚体，且没有接触、止挡或支承切换；
- 总惯量保持正，角度没有越过当前平水面几何坐标图的有效范围；
- 不出现破波、通气、夹气、显著湿润滞回或多值水线；
- 轴耗散能够由当前黏性—平滑库仑模型表示；
- 存在占优的单一反对称尾流模态；
- 阻力、加入惯量、尾流和跨距相干函数的联合标定域覆盖当前 \(Re,Fr,We\)、几何、湿跨、角度、振幅和来流变化率；
- 来流变化足够慢，或其非定常影响已经显式包含在闭合函数中；
- 所有闭合函数均有单位、归一化、来源、不确定度和适用域记录。

### 九、明确排除或触发停止的现象

下列情况首次发生时，当前光滑单模态模型应停止给出后继装置级预测，而不是只提高时间步或继续调参：

- 摆体或圆柱与槽壁、槽底、止挡发生接触；
- 总惯量低于允许下界，或状态离开允许角域；
- 工况离开联合标定域；
- 立方尾流饱和系数不再保证有界，而又没有经过验证的五次闭合；
- 出现破波、通气、夹气或显著接触线滞回；
- 尾流出现两个以上无谱隙的主模态；
- 出现显著三维端部自由度或跨湿段幅相无法由单一模态表示；
- 必需输入、闭合函数或初始尾流状态缺失。

这些失败意味着需要新的流体记忆、多模态/五次正规形、动态自由表面、三维流固耦合或非光滑机械模型，不能在当前方程中隐式改变参数来维持拟合。

## 主要输入与输出

主要输入包括：

- 主轴位置、圆柱半径和轴向范围、水槽宽度、水深、端隙及粗糙度；
- 刚性总成质量、质心和绕真实主轴的干结构惯量；
- 弹簧几何、刚度、原长、扭转势和轴耗散参数；
- 流体密度、黏度、重力和表面张力；
- 外缘来流 \(U_e(r,t)\)；
- 加入惯量、阻力、尾流、耦合和有限湿跨复相干闭合；
- 摆角、角速度和尾流复振幅初态；
- 预测时段、允许角域、最小惯量和联合标定域。

理论和程序应输出或能够重建：

- 摆角、角速度、角加速度及指定观测点的横流位移和速度；
- 各站位的湿润状态、排水体积、湿投影面积和湿跨；
- 重力、弹性、静水、阻力、尾流和外部控制力矩；
- 机械能、阻力耗散、支承耗散和尾流—机械交换功率；
- 尾流模态的幅值、相位及当前无量纲工况；
- 干燥、部分浸没、全浸没分支和模型域状态；
- 首个越域事件及最后可信状态。

## 参数识别与验证边界

阻力系数、加入惯量、尾流增长率与频率、非线性系数、摆—尾流耦合和湿跨复相干函数应来自独立的固定体、规定运动、流场或机械端口数据。通用文献中的 \(St\)、\(C_D\) 或尾流振子参数只能作为先验，不能直接冒充本装置的实测闭合。

需要严格区分：

- 方程的量纲、对称性、极限和能量记账正确；
- 数值实现通过单元测试和收敛检查；
- 低阶闭合在独立数据上完成辨识；
- 同一参数集能同时预测摆角、相位和水动力矩；
- 留出工况误差位于预先给定的不确定度范围内。

只有证据链完整时，才能把振幅增长、锁频区间或平均功率符号表述为真实装置的定量预测。短时烟雾测试、单条轨迹吻合或模型内部能量闭合均不足以完成物理验证。
