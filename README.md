# IYPT 2027 第 13 题：涡流摆

本仓库研究 IYPT 2027 第 13 题 **Vortex pendulum**：有限尺寸圆柱摆部分浸入来流中，刚体横流运动与尾流涡脱落相互耦合。准稳态阻力通常消耗机械能，而非定常尾流载荷既可能向摆输入能量，也可能从摆吸收能量，因此系统可能出现振幅衰减、振幅增长、极限环、锁频、共振和分岔。

项目目标不是只拟合一条摆角曲线，而是建立一个从装置几何、质量与惯量、支承、来流、流体物性、水动力模型和完整初始状态出发即可计算摆体—尾流联合演化的前向预测模型，并明确区分各项能量的输入、输出和耗散。

## 项目定位与阅读入口

本项目围绕实验现象预测，积累理论、实现、数值证据和实验数据。

[下一阶段计划](00_项目管理/Codex_下一阶段工作计划.md) 说明接续范围与验收；[当前交接](00_项目管理/交接说明_current.md) 查看真实进度、未解决问题和下一步；[目录指南](00_项目管理/README.md) 定位材料；[工作规范](AGENTS.md) 规定维护方式。主页保留稳定研究介绍与物理假设，不重复维护动态测试计数、阶段口令或待办。

## 研究内容

本项目分为四个相互区分、但可以相互验证的研究层次：

1. **前向预测理论**：建立刚体单自由度动力学、精确平水面浸没几何、静水力、加入惯量、准稳态阻力和尾流模态的耦合模型。
2. **前向理论的数值实现**：数值求解摆角、角速度和尾流复模态，并计算湿跨、水动力矩、功率以及模型当前是否仍处于适用范围内。
3. **高保真流体模拟**：使用更完整的流固耦合模型，检验降阶水动力模型、相位关系、二维/三维效应和能量收支。
4. **结构性研究**：研究振幅增长或衰减、锁频、共振舌、极限环、稳定性和分岔。

基线前向模型标识为 `VP-FWD-P0-SL1-v1`：

- `P0` 表示固定水平主轴、主轴与平均来流平行、横流单自由度的刚性圆柱摆拓扑；
- `SL1` 表示用一个复尾流模态描述占优的一级反对称涡脱落结构。

详细方程见 [`01_最终理论/01-前向预测理论.md`](01_最终理论/01-前向预测理论.md)。正式前向程序可按配置选择 `VP-FWD-P0-SL1-SS-v1` 低速粘滑、`VP-FWD-P0-SL1-DW-v1` 方向湿宽阻力及显式组合分支。它们需要各自的摩擦阈值、阻力参考和联合覆盖，不自动提高装置精度。实验输入见 [最小准备清单](04_实验与数据/实验前最小准备.md)，实际验证和未解决项以当前交接为准。

## 前向预测理论采用的物理假设

以下假设是当前模型为了把题目转化为一个可以由给定参数和初始状态直接求解的初值问题而采用的物理近似。它们不是 IYPT 题面额外规定的条件，也不代表所有“涡流摆”装置都属于同一模型。保持圆柱竖直平移的摆、球摆、柔索摆、多自由度悬挂或不同主轴方向都需要重新建立动力学。

### 一、装置拓扑与自由度

- 圆柱在参考平衡位置时轴线竖直。
- 主轴固定、水平，并与平均来流方向平行。
- 整个刚性总成只绕该主轴转动，机械状态由摆角 `theta` 和角速度 `omega` 描述。
- 不包含主轴平移、圆柱自转、扭摆、球面摆动、柔性摆臂或支架振动等额外自由度。
- 圆柱、摆臂、夹具和配重可以共同贡献总质量、质心位置和绕真实主轴的干结构转动惯量，但这些量必须按同一个刚性总成测量或计算。
- 在预测区间内，总成被视为刚体，不发生实体接触、止挡碰撞、支承方式切换或机械松脱。

### 二、进水实体与浸没几何

- 基线模型中，只有封闭的有限半径圆柱进入水中、排开液体并接受水动力载荷；摆臂、夹具和配重保持干燥。
- 圆柱按平端、刚性、有限半径的实体几何处理，而不是零半径线段，也不是整根都具有同一横流速度的平移体。
- 不同轴向位置到主轴的距离不同，因此局部横流速度为 `r * omega`，水动力矩必须沿实际浸没长度积分。
- 平均自由表面取固定平面 `z = eta_0`。模型通过圆柱与该平面的精确几何交集计算浸没截面积、湿投影宽度、排水体积和静水势能。
- 动态自由表面、波面爬升、破波和接触线运动不作为独立状态求解；只有在已经辨识的经验或低阶关系中，才可以间接影响水动力参数。
- 干燥、部分浸没和全浸没三种状态具有统一的几何定义，但不等于完整尾流动力学跨全干连续。正式四状态预测限定在正湿面积的联合标定域内；干机械对照独立选择，不隐式拼接干出—再入水或施加人工冲量。

### 三、刚体恢复力与机械耗散

- 重力、线性弹簧和可选扭转弹簧通过势能进入方程，弹簧力臂随真实几何变化，不用固定的“小角等效刚度”代替完整几何。
- 静水浮力通过浸没实体的势能及其角度导数进入，只计算一次；不能在经验水动力项中再次重复加入静水恢复力。
- 基线用角度相关黏性与平滑库仑摩擦；SS 分支改用独立静/动摩擦阈值与“可粘则保持粘着”的模式选择。粘着期间尾流仍演化，模式切换不重置状态。
- 外部控制、制动或驱动力矩可以作为已知输入加入，但必须明确其方向、功率符号以及时间或状态依赖关系。
- SS 只补理想静止/滑动，不包含机械间隙、碰撞、预滑弹性、接触老化及支承结构弹性模态。平滑摩擦速度直接改变低速损耗，不是无物理影响的数值设置。

DW 只按真实局部湿圆盘投影替换准稳态阻力宽度，并需要相应系数；不改变尾流的参考湿宽或以几何修正代替水动力标定。尾流的线性频率与非线性饱和频率分开定义，固定幅相规范不等于所有参数已可辨识。

### 四、来流与流体物性

- 流体密度记为 `rho`，运动黏度记为 `nu`，重力加速度记为 `g`，表面张力记为 `sigma`；这些量在当前工况内视为已知。
- 外缘来流 `U_e(r,t)` 是未受圆柱自身扰动的规定顺流速度，可以随浸没位置和时间变化。
- 当前前向模型不同时求解完整水槽流场；来流作为外部输入给定，圆柱对整个上游流场的反馈只通过已经校准的水动力模型间接体现。
- 平均来流方向与主轴平行，主要机械响应沿横流方向。如果存在显著横向平均流、主轴偏斜或左右不对称，就必须把这些因素显式加入模型。
- 水槽宽度、水深、端隙和粗糙度等通过无量纲参数影响水动力关系。不能把无限域圆柱的通用系数直接当作有限水槽、部分浸没装置中的精确常数。

### 五、水动力分解

当前模型把真实湿面牵引产生的总水动力矩分解为四部分：

1. **静水作用**：由平水面浸没几何和静水势给出。
2. **加入惯量**：用随构型变化的加入转动惯量 `J_a(theta)` 表示已经从流体牵引中单独分离出的惯性部分。
3. **准稳态阻力**：按每个浸没位置的局部相对速度、湿投影宽度和阻力系数 `C_D` 积分。
4. **非定常尾流载荷**：由复尾流模态产生升力和可选的直接截面力矩。

为避免重复计算，这四类作用必须按照同一套定义使用。如果高保真流体牵引已经包含静水、非定常惯性、阻力和尾流效应，就必须重新定义低阶分解，并删除已经被高保真模型包含的对应项，不能把两套载荷直接相加。

准稳态阻力要求满足 `Q_D * omega <= 0`，也就是说它在当前符号约定下只能耗散机械能，不能持续向摆注入能量。平均流向摆输入能量的可能性由非定常尾流载荷承担。

### 六、单一复尾流模态假设

- 当前 `SL1` 模型假设目标工况内存在一个占优的反对称尾流 Hopf 模态，并且它与其他模态之间存在可分辨的谱隙。
- 尾流状态由一个复振幅 `A = A_R + i A_I` 表示，并使用带线性增长/衰减、固有频率、立方饱和和非线性频移的 Stuart–Landau 型方程。
- 摆体位移、速度和加速度可以通过已经标定的复耦合系数驱动尾流；尾流再通过有限浸没长度上的复相干函数产生升力和力矩。
- 不同浸没位置处的尾流幅值和相位被近似表示为同一个全局模态乘以 `chi_L(r; Pi)` 或 `chi_M(r; Pi)`。如果实测跨距结构无法用这种分离形式表示，单模态假设就不再成立。
- 尾流系数、耦合系数和复输出函数依赖 `Re`、`Fr`、`We`、浸没长度比、阻塞比、端隙、粗糙度和运动幅值等工况，必须在实际使用范围内完成联合标定。
- 单复模态只是一个低阶尾流模型，不是完整 Navier–Stokes 方程的替代名称。仅凭几何和水的物性无法从零唯一确定所有尾流参数。
- 初始尾流状态必须明确给定，不使用隐藏随机噪声来启动振荡。

### 七、加入惯量与自由表面假设

- 随构型变化的加入惯量 `J_a(theta)` 只有在它已经从瞬时流体牵引中独立辨识时才使用。
- 总惯量 `J = I_O + J_a` 必须始终为正，并高于预先规定的下限；如果加入惯量随角度变化，对应的 `0.5 * J'(theta) * omega^2` 项不能省略。
- 平均自由表面被当作平面，因此模型不直接计算动态水面、表面波、局部爬升、通气或夹气。
- 表面张力仍可通过 `We` 等无量纲数影响水动力参数，但这不等同于显式求解动态自由表面。
- 如果动态自由表面与尾流或摆体运动发生强耦合，就需要升级为包含自由表面状态的模型。

### 八、用于实际装置定量预测的条件

要把当前模型用于实际装置的定量预测，需要同时满足：

- 装置确实符合 `P0` 拓扑，主轴固定并与平均来流平行；
- 整个运动总成可以近似为刚体，并且没有接触、止挡或支承方式切换；
- 总惯量始终为正，角度没有超出当前平水面几何模型的适用范围；
- 不出现破波、通气、夹气、显著润湿滞回或多值水线；
- 轴承和支承耗散能够由当前黏性阻尼—平滑库仑摩擦模型表示；
- 尾流中存在一个占优的反对称模态；
- 阻力、加入惯量、尾流和跨距相干函数的标定工况覆盖当前 `Re`、`Fr`、`We`、几何、浸没长度、角度、振幅和来流变化率；
- 来流变化足够慢，或者其非定常影响已经显式包含在水动力模型中；
- 所有经验或低阶水动力关系都有明确的单位、归一化方式、参数来源、不确定度和适用范围。

### 九、当前模型的停止条件

一旦发生下列情况，当前单模态模型不再适用于后续的定量预测：

- 摆体或圆柱与槽壁、槽底或止挡发生接触；
- 总惯量低于允许下限，或状态离开允许角度范围；
- 首次全干，或工况先离开有依据的联合标定覆盖范围；
- 立方尾流模型已经不能保证解有界，而又没有经过验证的更高阶尾流模型；
- 出现破波、通气、夹气或显著接触线滞回；
- 尾流出现两个以上强度相近、没有明显谱隙的主模态；
- 出现显著三维端部效应，或者不同浸没位置处的幅值和相位无法由单一全局模态表示；
- 必需输入、水动力参数或初始尾流状态缺失。

这些情况应先区分缺失输入、实现错误与物理模型失效；确需续接时再按证据选择流体记忆、多模态、动态自由表面或接触等扩展，不自动同时加入所有机制，也不能临时调整参数继续拟合结果。

## 主要输入与输出

主要输入包括：

- 主轴位置、圆柱半径和轴向范围、水槽宽度、水深、端隙及粗糙度；
- 刚性总成质量、质心和绕真实主轴的干结构转动惯量；
- 弹簧几何、刚度、原长、扭转势和轴耗散参数；
- 流体密度、黏度、重力和表面张力；
- 外缘来流 `U_e(r,t)`；
- 加入惯量、阻力、尾流、摆—尾流耦合和有限浸没长度上的复相干参数；
- 摆角、角速度和尾流复振幅初始状态；
- 预测时段、允许角度范围、最小惯量和参数标定范围。

理论和程序应输出或能够重建：

- 摆角、角速度、角加速度以及指定观测点的横流位移和速度；
- 各位置的浸没状态、排水体积、湿投影面积和总浸没长度；
- 重力、弹性、静水、阻力、尾流和外部控制力矩；
- 机械能、阻力耗散、支承耗散以及尾流与机械系统之间的交换功率；
- 尾流模态的幅值、相位和当前无量纲工况；
- 干燥、部分浸没、全浸没状态以及模型是否仍处于适用范围内；
- 首个越界或失效事件以及最后可信状态。

## 参数识别与验证要求

阻力系数、加入惯量、尾流增长率与频率、非线性系数、摆—尾流耦合和有限浸没长度上的复相干函数，应来自独立的固定体实验、规定运动实验、流场测量或机械端口数据。通用文献中的 `St`、`C_D` 或尾流振子参数只能作为先验参考，不能直接当成本装置已经测得的参数。

需要严格区分：

- 方程的量纲、对称性、极限行为和能量收支是否内部一致；
- 数值实现是否通过单元测试和收敛检查；
- 低阶水动力参数是否在独立数据上完成辨识；
- 同一组参数是否能够同时预测摆角、相位和水动力矩；
- 未参与参数辨识的留出工况是否落在预先给定的不确定度范围内。

只有这些证据都具备时，才能把振幅增长、锁频区间或平均功率方向表述为对真实装置的定量预测。短时烟雾测试、单条轨迹吻合或模型内部能量收支一致，都不足以完成物理验证。
