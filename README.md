## Markdown 公式约定

- 行内公式使用 `$...$`，独立公式使用单独成行的 `$$` 定界符。
- 不使用 `\(...\)` 或 `\[...\]`；表格公式内的绝对值符号使用 `\lvert` / `\rvert`，避免被解析为列分隔符。
- 从仓库根目录执行 `python3 tools/check_markdown_math.py` 检查活动及非冻结 Markdown 的公式语法。
- `03_项目资料/04-审查与交付归档/`、历史审查和当前审查的原始同步包保持生成时的字节身份，不做批量语法改写，也不纳入本检查器。
