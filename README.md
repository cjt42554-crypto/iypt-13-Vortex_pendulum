# IYPT 2027 第 13 题：涡流摆

本仓库研究 IYPT 2027 第 13 题 **Vortex pendulum**：有限尺寸圆柱摆置于来流中，刚体运动与尾流涡脱落相互耦合，流体可能向摆输入机械能，也可能耗散机械能。项目关注来流、浸没状态、几何、惯量、支承和阻尼等参数对振幅、频率、相位与稳定性的影响。

## 项目目标

建立包含刚体动力学、静水力、湿跨、加入惯量、阻力和尾流模态的前向预测模型，并通过降阶求解器、高保真流体模拟与结构性分析研究振幅增长或衰减、锁频、共振、分岔和能量传递。

## 仓库结构

- [`01_最终理论/`](01_最终理论/)：前向预测理论、数值计算理论和结构性理论。
- [`02_模拟程序/`](02_模拟程序/)：模型、求解器、高保真流体计算、分析工具、交互界面和自动化测试。
- [`90_候选工作区/`](90_候选工作区/)：尚未正式提升的研究、审计、验证证据和交接记录。
- [`AGENTS.md`](AGENTS.md)：仓库协作与修改规范。
