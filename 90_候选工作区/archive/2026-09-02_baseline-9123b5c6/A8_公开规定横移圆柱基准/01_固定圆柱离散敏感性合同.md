# A8 固定圆柱离散敏感性合同

## 1. 目的与边界

当前 A8 裁决为 `NO-GO-A8-FIXED-REFERENCE-MISMATCH`。最细已运行网格 $N_D=16$ 的固定圆柱尾流成熟、数值稳定且 $St$ 进入冻结文献容差，但平均阻力和升力 RMS 显著偏高。

本轮只回答一个问题：在不改物理输入、不调文献目标的前提下，偏高载荷对格点相位、弥散 mask 半厚度和无量纲惩罚尺度分别有多敏感？

本合同不运行规定横移长时分支，不重算 weak-FSI，不修改前向理论，也不把任一单点与文献的接近解释为校准成功。

## 2. 运行前冻结的共同输入

完整 research profile 固定：

- $Re=185$；
- $N_D=16$；
- $U_{lu}=0.05$；
- 数值域 $23D\times10D$；
- 圆柱中心距入口名义值 $3.5D$；
- 固定圆柱运行 80 个对流时间；
- 舍弃前 40 个对流时间；
- 横向周期边界和当前开口入口/出口实现不变；
- A2 半步体力虚拟内部流体动量修正和系数定义不变。

smoke profile 使用 $N_D=8$、12 个对流时间并舍弃前 6 个，只验证四类代码路径可达，不作定量裁决。

## 3. 一次一因素矩阵

原基线为：格点偏移 $(0,0)$、mask 半厚度 $0.75$ 格、无量纲惩罚尺度 $\hat\eta=0.00625$。

research 共 9 个唯一算例：

| ID | 分组 | $\Delta x$ | $\Delta y$ | mask 半厚度 | $\hat\eta$ |
|---|---|---:|---:|---:|---:|
| `baseline` | baseline | 0 | 0 | 0.75 | 0.00625 |
| `phase-x-half` | grid-phase | 0.5 | 0 | 0.75 | 0.00625 |
| `phase-y-half` | grid-phase | 0 | 0.5 | 0.75 | 0.00625 |
| `phase-xy-half` | grid-phase | 0.5 | 0.5 | 0.75 | 0.00625 |
| `mask-half-0p50` | mask-half-thickness | 0 | 0 | 0.50 | 0.00625 |
| `mask-half-1p00` | mask-half-thickness | 0 | 0 | 1.00 | 0.00625 |
| `mask-half-1p25` | mask-half-thickness | 0 | 0 | 1.25 | 0.00625 |
| `eta-half` | penalization | 0 | 0 | 0.75 | 0.003125 |
| `eta-double` | penalization | 0 | 0 | 0.75 | 0.0125 |

这里的 $\Delta x,\Delta y$ 是以格为单位、相对于已提交基线圆心的附加偏移。格点相位组用半格移动，不改变名义直径、Reynolds 数或入口速度。

## 4. 预先冻结的指标和门

每个算例输出：

- $\bar{C}_D$；
- $C_{L,\mathrm{rms}}$；
- $St$；
- 前后半窗平均阻力和升力 RMS 漂移；
- 最大运行中 Mach 数和最大密度偏差；
- 相对于固定文献目标的归一误差分数。

共同硬门沿用 A8：

- 最大密度偏差不超过 8%；
- 最大运行中 Mach 数不超过 0.30；
- 平均阻力半窗漂移不超过 5%；
- 升力 RMS 半窗漂移不超过 10%。

新运行器还必须以 $10^{-12}$ 的最大相对差复现已提交 $N_D=16$ 基线的 $\bar{C}_D$、$C_{L,\mathrm{rms}}$ 和 $St$，否则停止解释敏感性。

每个因素的载荷敏感性幅度定义为该组任一算例相对基线的 $\bar{C}_D$ 或 $C_{L,\mathrm{rms}}$ 最大相对差。只有幅度至少为 5%，且为第二大因素的至少 1.5 倍，才称该因素“主导”；否则分别记为 `multi-factor` 或 `insufficient`。

## 5. 失败闭锁裁决

1. 数值稳定门失败：`STOP-A8S-NUMERICAL-STABILITY`。
2. 任一完整算例统计窗不成熟：`NO-GO-A8S-WAKE-NOT-MATURE`。
3. 原基线不能确定性复现：`STOP-A8S-BASELINE-NONREPRODUCIBLE`。
4. 任一单因素点进入全部固定圆柱文献容差：`INCONCLUSIVE-A8S-SINGLE-FACTOR-HIT-NOT-QUALIFIED`；这只提示可能的误差抵消，不能验收。
5. 没有单点进入全部容差：按 `grid-phase`、`mask-half-thickness`、`penalization`、`multi-factor` 或 `insufficient` 输出对应 NO-GO 诊断。

本矩阵没有 A8 PASS 出口。固定基线只有在后续网格、Mach、域和离散参数联合收敛中再次进入冻结文献容差，才可能解除规定横移长时分支的闭锁。
