## 2. 唯一活动目标

活动目标不再是找到全局最优硬件或形式闭合全部仓库门禁，而是：

> 对预先冻结的留出实验工况给出带不确定度的现象预测，使趋势、主频、幅值和平均功率符号达到预先约定的误差要求；数值误差明显小于参数不确定度和模型形式误差；任何未通过定量物理资格的后端不得被包装成装置定量预测器。

实验前可暂停的判据是：所有对上述目标仍有实质贡献、且不需要新实验数据的工作已经完成或由有上限的科学去留测试明确停止；剩余事项只依赖装置测量、标定数据或留出实验结果。

## 3. 必须保留的科学工作

### 3.1 冻结预测问题

在读取留出实验结果前，记录：

- 装置版本、流速、水深和初始角度范围；
- 预测时间窗和释放方式；
- 标定工况与留出工况；
- 是否增长、主频、幅值、建立时间、相位和平均功率符号；
- 实验噪声、误差指标和接受阈值。

Pro 给出的主频约 5%、临界流速约 10%、幅值约 15%，以及趋势和功率符号必须正确，只是待实验噪声确认的起始建议，不是已经冻结或验证的门值。

### 3.2 装置与机械标定

需要真实测量几何、质量、质心、转动惯量、刚度、黏性/库仑/静摩擦、水温与流体性质、来流均匀性和初始条件，并为每项给出不确定度。

无流自由衰减和多初始幅值衰减用于分离有效惯量、支点阻尼、库仑摩擦、可能的非线性刚度和重复释放误差。输出只需一个简单的 `apparatus-calibrated.json`，包含数值、单位、不确定度和测量方法。

### 3.3 ROM 参数辨识与留出预测

优先辨识可观测的低维组合，而不是分别拟合所有抽象系数：

- 有效附加惯量；
- 阻力矩系数组合；
- 尾流增长、饱和和耦合强度；
- 力与速度相位；
- 有限湿跨相干因子及其随流速和浸没深度的低维变化。

正式 ROM 是活动预测主后端。保存参数最优值、可信范围、相关性、适用范围、标定 condition block 和未使用的留出 block。

在读取留出结果前生成预测区间并提交配置和系数包；读取后使用现有比较工具评估误差。只有残差明确指向某个缺失机制时，每次增加一个可证伪机制。

### 3.4 最小数值可信度

对实际采用的 ROM 保留：

- 三档 ODE 容差；
- 湿几何解析/积分检查；
- 能量余额与事件检查；
- 变惯量导数项和输出积分检查；
- 参数扰动、不确定度传播和同输入重复运行；
- 非有限值与适用域检查。

停止条件是数值误差低于总预测不确定度约三分之一，或已经明显小于参数和模型形式误差。达到后不再追求跨所有平台逐字节一致。

## 4. 二维 CFD 的一次有上限去留循环

二维 CFD 当前未通过公开固定圆柱力幅值基准，且缺少有限湿跨、端部、自由表面和三维失相干机制。因此它不是当前装置的定量预测主后端。

只允许一次有上限的非实验科学修正循环：

1. 选定一个公开固定圆柱基准和文献接受区间；
2. 使用合理分辨率，定位并修正最可疑的边界、力提取或 Brinkman 模型问题；
3. 执行三档网格及必要的 Mach 和域敏感性检查；
4. 检查平均阻力、升力 RMS 和 Strouhal；
5. 强制二选一：
   - 进入合理文献误差范围：仅作为辅助模型继续研究幅值、相位和功率闭合；
   - 仍明显失配：冻结为定性流场工具，停止 HW2R、H2-X/H2-N 和长时 A8R 性能路线。

即使二维基准通过，也不能自动升级为有限湿跨装置的定量验证。

## 5. 只保留的最小工程保障

- 轨迹级并行；
- 基础 wall-clock timeout；
- 只终止本任务 child/process group；
- 峰值内存检查；
- case 级原子 shard 和不同输出目录；
- 对最终实际采用后端做 2 至 3 个缩短 case 与 1 个较大 case 的数值等价检查；
- Git commit、完整配置、系数包来源、随机种子、运行时版本、输出 checksum 和简短日志。

只有必要科学矩阵无法在实际准备窗口内完成时才做性能优化。顺序是：先测串行墙钟和峰值内存，再做轨迹级并行；仍不够时只比较一个 native/SIMD 或一个 GPU 方案。达到所需科学计算的周转时间后立即停止，不搜索 95% 全局最优，也不测试完整核数、pinning 或 hybrid 比例矩阵。
