## 八种入口机制

1. S1 `legacy-zou-he-derived-density`：正式速度 Zou--He；密度由已知人口推导，只重构三个未知入射人口。
2. S2 `legacy-zou-he-density-normalized`：先执行 S1，再把左边界节点九个人口等比例归一到 $\rho=1$；保持局部速度和归一化人口形状。
3. S3 `incoming-equilibrium-derived-density`：沿用 S1 推导密度，只把三个未知入射人口替换为平衡项。
4. S4 `incoming-regularized-derived-density`：沿用 S1 推导密度，只把三个未知入射人口替换为平衡项加正则化非平衡应力。
5. S5 `full-equilibrium-derived-density`：沿用 S1 推导密度，以平衡分布覆盖九个人口。
6. S6 `full-regularized-derived-density`：沿用 S1 推导密度，以平衡项加正则化非平衡应力覆盖九个人口。
7. S7 `full-equilibrium-fixed-density`：使用 $\rho=1$ 和目标速度，以平衡分布覆盖九个人口。
8. S8 `full-regularized-fixed-density`：使用 $\rho=1$ 和目标速度，以平衡项加正则化非平衡应力覆盖九个人口；该策略对应 A8K 入口锚。

S3 和 S4 通常不能同时精确施加目标密度与速度，故合同只要求记录实际矩残差，不把它们描述为精确规定状态边界。A8L 没有构造数学上过定的机械 2×2×2 全因子组合。

## 因果解释

冻结矩阵支持以下窄结论：

1. S1 为 0/9、S2 为 9/9，因此只增加边界密度归一化在该矩阵内已足以越过密度和 Mach 门。
2. S5 为 0/9、S7 为 9/9；S6 为 0/9、S8 为 9/9。固定密度在平衡全状态族和正则化全状态族内都构成充分增量。
3. S3 与 S5 均为 0/9，S4 与 S6 均为 0/9。只把覆盖范围从三个入射人口扩展到九个人口，在仍使用推导密度时并不足以过门；这不证明九人口覆盖在一般边界中没有作用。
4. S7 与 S8 均为 9/9，因此正则化非平衡应力不是固定密度全状态族在该冻结矩阵内的稳定必要条件。
5. S3 与 S4 均为 0/9，S5 与 S6 均为 0/9，因此正则化非平衡应力在使用推导密度时也不是充分条件。

八种策略中，所有通过策略都直接控制 $\rho=1$，所有继续使用 Zou--He 推导密度的策略都失败。该结果把“入口侧”进一步缩小到“入口密度控制”这一稳定杠杆，但不证明某一种正式边界离散具有正确的反射性能、质量守恒或物理精度。

S2 是对现有 Zou--He 形状的最小候选因果探针，S7 是固定密度平衡全状态探针；Codex 不在本报告中自行选择二者之一作为正式算法。尤其是，S2 的逐步九人口归一化仍是候选 wrapper，不得直接复制到正式步进路径。
