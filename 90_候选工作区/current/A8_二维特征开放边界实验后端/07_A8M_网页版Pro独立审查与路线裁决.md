- 没有改变策略集合、108 算例矩阵、12 个声学案例、执行次序或科学门槛；

因此 V2 可以作为**修订后预注册研究**接受，但不得描述为“首轮预注册一次通过”。这一勘误不削弱对 S2 的拒绝：S2 的质量和反射失败来自修订后完整矩阵，并且相对门槛的超限幅度不是半格几何误差可以解释的。

## 5. 为什么正式拒绝 S2

### 5.1 启动稳定不等于边界资格

S2 在三种协议、九个参数角点下均满足密度和 Mach 门，启动稳定为 27/27。但稳定性只是必要条件之一，不能覆盖质量、反射和内部场失败。

### 5.2 S2 的离散质量源过大

冻结门要求：

- 累计适配器净质量相对初始质量不超过 $10^{-3}$；
- 相对正式边界绝对交换不超过 $1\%$；
- 非入射绝对改写不超过全部绝对改写的 $50\%$。

S2 在静止 20D 缓启动中的适配器净质量达到初始质量的 0.233334--0.240550；在固定物体预运行协议中仍达到 0.037717--0.052812。合并启动和声学账本后，非入射方向占全部绝对改写的 0.779997。

因此 S2 虽然代码形式只是一次统一缩放，但在离散动力学上不是“小修正”。它主要修改了出射人口及静止/横向人口，而不是只处理进入计算域的自由度。

均匀目标流案例中的适配器改写只有浮点舍入量级，其非入射比例因分母趋近零而缺乏独立物理意义；这不改变静止启动和固定物体两类非平凡协议的明确失败。

### 5.3 S2 未通过上游声学反射门

S2 的三个松弛时间均失败：

- 特征振幅反射比：5.211%--6.640%，门槛为不超过 5%；
- 声学信号能量比：0.292%--0.475%，门槛为不超过 0.25%。

入射检测、参考域一致性、相位和平均状态漂移门均通过，所以失败不能归因于脉冲没有到达、参考平移错误或平均流失控。

当前代码中的“声学能量反射比”是特征信号平方和之比，没有额外乘以平均流下的群速度比，因此应理解为冻结的操作性信号能量指标，而不是完整连续介质能流。这个术语边界不改变裁决：S2 已独立失败特征振幅门；若加入上、下游特征速度的能流修正，反射能量不会改善到通过。

### 5.4 S2 改变内部解

S1 与 S2 只在均匀目标流、无物体协议下 9/9 等价。静止缓启动和固定物体已建立来流协议的内部场比较均为 0/9：

- 静止缓启动速度 RMS 差达到入口速度的 82.260%--84.354%；
- 固定物体协议仍为 5.516%--6.872%；
- 固定物体密度 RMS 差为 0.005366--0.005597。

所以 S2 不能被解释为“只消除入口附近数值峰，而内部流场基本不变”。

### 5.5 策略处置

- S2：正式淘汰；不得通过放宽 5%、0.25%、1% 或 50% 门槛追认；
- S7、S8：继续只作固定密度强投影因果对照，不进入正式候选；
- S1：保留为 legacy 基线；
- 任何以后只处理入射特征或入射人口的算法都必须使用新策略 ID，不得沿用 S2 名称或继承 S2 的 PASS。

## 6. legacy 已建立来流路线的正确解释

A8M 表明：

- S1 在静止全域加 20D 入口爬升时为 0/9 稳定；
- S1 在均匀目标流、无物体初场下为 9/9 稳定；
- S1 在固定物体预运行一个窗口后，再审计一个等长窗口时为 9/9 稳定；
- 固定物体审计窗最大密度偏差为 0.028404--0.032544，最大 Mach 为 0.219706--0.226837；
- 精确质量账闭合。

因此，当前启动异常更适合解释为“静止全域与入口加速协议不相容”，而不是必须通过密度归一化入口修复。对于实验中先建立来流、再释放摆体的准备过程，保留 legacy 并使用预运行/相容初始化是优先的启动路线候选。

但 A8M 尚未证明：

1. 一个预运行窗口已经达到统计成熟或周期稳定；
2. 固定物体到规定运动或 weak-FSI 的释放瞬态无伪冲击；
3. 预运行时间对载荷和尾流不敏感；
4. 该协议与实际实验准备过程一致；
5. legacy 入口具有低反射资格。

尤其是，S1 的特征振幅反射比为 86.657%--87.536%，声学信号能量比为 81.066%--82.390%。所以“legacy 已建立来流启动稳定”绝不能写成“legacy 开放入口合格”。它只是在当前正式边界身份下避免启动密度峰的操作路线。

## 7. 对正式重构的路线裁决

### 7.1 Stage 1 可以与新算法选择分离

在科学上，可以先执行重构合同 Stage 1：只把现有 legacy 入口/出口抽离为一级策略接口，并要求所有 legacy 结果逐值不变。该阶段不需要选择 S2，也不宣称边界物理质量提高。

但当前用户指令只是要求审查 Codex 结果，并未明确授权修改 `02_模拟程序/**`。因此本轮不启动 Stage 1。

用户明确授权后，Codex 的 Stage 1 只能：

- 抽离边界接口；
- 保持默认入口和出口均为 legacy；
- 保持 MRT、Brinkman、迁移、SI 映射和 A1 力功记账不变；
- 禁止 checkpoint/restore 外层覆盖、自动 fallback、限幅和参数特判；
- 精确复现 A8J、A8H 和 A8M 的 legacy 锚；
- 执行正式程序完整 `npm run validate`；
- 完成后停止并交回独立审查，不得顺带接入新入口或 CBC。

### 7.2 新入口必须是新算法身份

如果项目仍要求低反射入口，下一候选算法应只处理入射特征或入射人口，保留由内部流场带到入口的出射信息。它必须重新预注册：

- 精确逐人口质量账；
- 上游声学反射绝对门；
- 静止启动、相容初场和固定物体预运行协议；
- 内部场与载荷差异；
- 参数角点和独立复跑。

这是一项新数值算法研究，不是对 S2 继续打补丁。

## 8. 当前结论上限

A8M 成功完成了两件事：

1. 用精确逐人口账证明 S2 的稳定改善伴随显著的人工质量和非入射人口改写；
2. 证明在相容初场或固定物体预运行下，legacy 可以避免本轮启动密度失败。

A8M 没有给出任何正式合格的低反射入口，也没有解除固定圆柱公开载荷、规定横移、weak-FSI 或装置预测的既有闭锁。

正式理论和正式程序本轮均未修改。正式程序 `npm run validate`、来源级高分辨率、网格--Mach--域联合收敛、规定横移定量长时、weak-FSI、三维、自由表面和实验验证均未执行。
