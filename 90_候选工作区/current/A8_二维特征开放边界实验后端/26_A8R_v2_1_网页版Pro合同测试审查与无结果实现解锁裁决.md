## 4. 合同测试覆盖审查

### 4.1 八算例矩阵与来源身份

测试逐项冻结：

- $D\in\{24,36,54\}$；
- 两个 mask 半厚度；
- 六条基线相位轨迹与两条 $D=54$ 半格相位轨迹；
- 确定性顺序、唯一 ID、网格尺寸、圆柱中心、步数、黏度、松弛时间、
  惩罚尺度及派生比值；
- v2.1 Markdown、机器合同、上一轮 Pro 裁决和正式 `lbm.ts` 的冻结
  SHA-256；
- A8Q 存储压缩产物的实际字节数与 SHA-256；
- $D=24$ 公共投影字段、零数值容差和 checkpoint 禁止语义。

测试通过完整机器合同哈希绑定，未单独断言的机器字段也不能在不使
身份测试失败的情况下静默漂移。

### 4.2 周期交叉、频带与积分

测试内部 oracle 覆盖：

- 原始正斜率过零谓词与线性插值；
- 先登记全部原始交叉、唯一选择最后 7 个；
- 少于 7 个交叉、重复交叉或非有限交叉的 INCONCLUSIVE 路径；
- 禁止跳过不合格交叉并向前寻找替代点；
- 六个周期逐一满足闭区间
  `1/0.24 <= T_j <= 1/0.15`；
- 单一正弦、精确样本零、高频小振荡、额外交叉半周期、漏失交叉
  双周期和两个频带边界；
- 端点插值、复合梯形积分、实际时长加权聚合、最小值、最大值和
  偶数中位数。

未发现允许两个符合测试的实现选择不同交叉序列或不同周期聚合定义的
缺口。

### 4.3 三分辨率趋势门

测试覆盖五类结果前人工样例：

- 同向且细一级增量严格缩小；
- 相邻增量反向；
- 已分辨但细一级增量未缩小；
- 包络重叠或包含零；
- 精确平台。

因此 `RESOLVED-PASS`、`RESOLVED-NO-GO` 与
`UNRESOLVED-INCONCLUSIVE` 的边界已被独立 oracle 固定。精确平台
不会被误判为 NO-GO。

### 4.4 双 mask、双相位主指标门

测试确认四类主指标均进入相同屏蔽：

- 平均阻力；
- 原始升力 RMS；
- 去均值升力 RMS；
- 平均周期。

测试枚举四条 $D=54$ 轨迹的全部 6 个无序轨迹对，并对每对生成
$6\times6=36$ 个逐周期比较；同时覆盖聚合严格 5% 门、逐周期最坏
严格 5% 门和等于阈值不通过。

A8Q 精确常数 `0.04995122077720906` 仍只额外约束基线相位的两种
聚合升力 RMS，没有扩展到阻力或周期。平均升力相对差仍被禁止。

逐周期 $6\times6$ 门同时吸收轨迹内部周期散布和轨迹间差异。它是
联合窄带屏蔽，不是纯相位效应估计。未来失败只能判 INCONCLUSIVE，
不得单独归因于 mask 或格点相位。

### 4.5 力身份、舍入账与终局

合同测试已冻结字段级边界：

- 原始人口动量恒等式与 A2 公式重算分离；
- 原始力独立构造的禁止输入；
- 逐人口、逐链路、逐格 Brinkman 力及逐格 $\chi\rho u$ 的绝对账；
- D2Q9 方向 0 至 8、格点和链路遍历顺序；
- 所有独立量形成后才允许读取正式比较值；
- `body=null` 使用对应冻结定义的控制体中心；
- 三终局代码、优先级、文献观察项和下游禁止项。

这些测试足以接受合同测试阶段，但它们仍主要验证机器声明和纯 oracle，
尚未验证未来实现对真实人口数组的控制体链路记账。因此合成 D2Q9
人口闭合必须成为下一阶段阻塞门。

## 5. 非阻塞限制与下一阶段强制门

### 5.1 A8Q 规范 JSON 尚未重新流式核验

本轮合同测试实际核验了 A8Q 压缩对象的存储字节数和 SHA-256；对
解压后 100,105,555 字节规范 JSON，只冻结了机器合同中的登记值，
没有重新流式计算规范 SHA-256。

这不阻塞合同测试接受，但下一阶段在任何 $D=24$ 锚导入之前必须：

1. 验证压缩对象存储字节数和 SHA-256；
2. 验证 sidecar 身份；
3. 流式 gunzip，不构造超大单字符串；
4. 计算解压规范 JSON 的字节数和 SHA-256；
5. 任一不一致立即失败，不得退回报告中的手抄标量。

### 5.2 Git LFS 实体化必须显式守卫

Git 树中压缩产物是 LFS 指针，运行环境可能没有完成 LFS 实体化。
无结果实现必须检测以
`version https://git-lfs.github.com/spec/v1` 开头的指针内容，并给出
明确失败信息；不得把 133 字节指针当作压缩产物，也不得静默跳过锚
核验。

### 5.3 合成 D2Q9 力身份必须成为实现级测试

下一阶段支持测试至少覆盖：

- 均匀无力人口场的零原始反力；
- 单条向外链路和单条向内链路的符号与分量；
- 轴向和对角八个移动方向；
- 已知局域动量变化与控制面通量的闭合；
- 非零 mask 或 Brinkman 力支撑落在控制体外时拒绝证据；
- 步前、步后人口及只读 checkpoint 逐元素一致；
- 独立宏观重建的固定 D2Q9 顺序与 Neumaier 求和；
- 原始力残差和 A2 残差分别注入失败，证明二者不能互相抵消；
- 使用会在提前访问时抛错的正式值 getter，证明读取屏障真实生效；
- 逐项绝对账和两类舍入上界按合同公式形成。

纯字段断言不能替代这些实现级合成测试。
