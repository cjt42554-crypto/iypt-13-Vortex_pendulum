# S1 结构工具合成资格结果前合同

## 1. 合同身份和范围

合同身份为：

`VP-S1-SYNTHETIC-STRUCTURAL-QUALIFICATION-CONTRACT-v1`

S1 只闭合实验前需要的最小结构工具：线性谱、特征多项式对照、合成 Hopf 横截性、
可辨识组合接口以及状态、功率、频率和相位分析。输入均为解析或合成数据，输出必须
标记 `synthetic-only`。

暂停前不实现完整周期轨道伪弧长延拓、Floquet、第一 Lyapunov 系数、Arnold 舌、
Bautin、环面、倍周期或混沌分类。这些对象只有在装置标定或 E1 数据触发后才恢复。

## 2. 冻结合成案例

必须覆盖：

- 非线性解析向量场的中心有限差分 Jacobian 三档步长收敛；
- 两个二阶块构成的四阶系统：特征多项式与独立解析特征根对照；
- Hopf 正规形在控制参数两侧的稳定性和横截性；
- 只暴露 `L_gamma_j` 可辨识组合、拒绝无证据拆分 `L` 与 `gamma_j`；
- 已知正弦状态的频率和相位；
- 已知状态与力的平均功率；
- 相同输入规范输出字节一致；
- 文献先验图必须显式标记为示例。

## 3. 冻结门值

Jacobian 误差随三档步长严格下降，两个相邻误差比均至少为 3。特征多项式代入每个
独立根后的归一残差不超过 `1e-10`。Hopf 横截性斜率与解析值相对误差不超过
`1e-8`，稳定性分类在参数两侧正确。

合成频率相对误差不超过 `1e-3`，相位绝对误差不超过 `2e-3 rad`，平均功率相对误差
不超过 `1e-3`。所有规范输出必须逐字节重复。

## 4. 结论

全部案例通过时记录：

`PASS-S1-EXPERIMENT-PREPARATION-STRUCTURAL-TOOLS`

未触发的非线性延拓工作记录为：

`DEFERRED-S1-NONLINEAR-CONTINUATION-AWAITING-CALIBRATION`

该 PASS 只证明合成工具，不证明装置分岔、锁频、功率趋势或任何实验状态。
