# H2-N 非逐字节后端分阶段数值资格预注册合同

## 1. 身份和触发器

机器合同身份为：

`VP-H2N-NUMERICAL-BACKEND-QUALIFICATION-CONTRACT-v1`

以下任一事实触发 H2-N：

- native、OpenMP、SIMD、GPU 或 hybrid 改变浮点或归约顺序；
- 候选改变数据布局、边界或归约；
- 候选不能通过 H2-X 逐字节门；
- H2-X 不是代表性最优，而 H2-N 候选预期端到端净收益超过 10%。

H2-N 必须使用新的 backend、algorithm、precision、layout、reduction 和 boundary 身份，不能冒充 TypeScript H2-X，也不允许 silent fallback。

## 2. stage-0 代表性可行性

stage-0 固定覆盖：

- D2Q9 equilibrium 和 moments；
- MRT collision；
- Guo forcing；
- Brinkman mask 和 force；
- scatter streaming；
- 开放和周期横向边界；
- `body=null`、baseline 固定体和 minus-half-cell 固定体；
- 人口、质量、动量和力交换；
- 指定 checkpoint 场量。

尺寸固定为：

- D24：804 x 240，32 步；
- D36：1206 x 360，24 步；
- D54：1809 x 540，16 步。

所有 fixture 在实现前由固定字符串 `sha256:IYPT13-H2N-STAGE0-FIXTURE-v1` 派生，只使用 Float64。

## 3. stage-0 数值门

归一化差异定义为：

`abs(candidate-reference) / max(abs(reference), abs(candidate), 1e-15)`

冻结上限为：

- equilibrium/moment 最大差异 5e-13；
- collision/forcing/streaming/boundary 最大差异 2e-12；
- population 归一化 L2 误差 1e-11；
- 质量和动量差异 1e-11；
- raw/A2 force 差异 5e-10；
- checkpoint field 归一化 L2 误差 1e-10；
- 非有限值数量为零；
- 负人口数量差异为零。

stage-0 只输出误差上界、布尔值、身份哈希、资源和失败码，不持久化科学场或装置量。

## 4. stage-0 性能门和四种出口

cold 和 steady-state 必须分开计时。三次正式重复各 15 至 60 秒，端到端比较包含 transfer、audit、shard 和 aggregation。

相对选中 H2-X 的代表性端到端净收益必须严格大于 10%，才触发完整 H2-N。否则有效停止为：

`DEFERRED-H2N-NO-MATERIAL-END-TO-END-GAIN`

stage-0 的其他出口为：

- `PASS-H2N-STAGE0-REPRESENTATIVE-FEASIBILITY`；
- `NO-GO-H2N-STAGE0-NUMERIC-OR-PERFORMANCE`；
- `DEFERRED-H2N-TOOLCHAIN-OR-RESOURCE`。

## 5. 条件完整数值资格

只有 stage-0 通过且净收益严格超过 10% 才执行完整资格。必须覆盖：

- 质量和动量账；
- 每步 Brinkman exchange；
- raw 和 A2 force；
- 边界负例；
- 稳定性；
- 网格、时间和精度敏感性；
- reduction 误差；
- 跨设备确定性；
- 统计输出容差；
- 两个独立实现，或一个实现加独立参考；
- 完整来源、编译器、驱动和设备身份。

完整资格冻结上限为：

- population 归一化 L2 误差 1e-10；
- 质量和动量账差异各 1e-10；
- 每步 Brinkman、raw force、A2 force 和边界通量差异各 1e-9；
- 统计输出归一化差异 1e-6；
- 非有限值为零；
- 网格/时间趋势方向、稳定性分类和全部负例必须一致。

完整通过码为：

`PASS-H2N-NUMERICALLY-QUALIFIED-BACKEND-CANDIDATE-ONLY`

该码只证明候选数值后端，不证明物理模型或实验。

## 6. 安全、证据和停止边界

资格必须在有限内存 cgroup 中执行，保留至少 4 GiB 或总内存 25%，swap 和 OOM 增量为零，不操作无关进程。外来 GPU 占用或工具链缺失只能产生资源 DEFERRED，不得停止其他进程。

持久证据只允许：身份哈希、误差上界、pass/fail 布尔值、时间、资源和失败码。科学 payload 不允许人工读取，不能写 A8R 规范主产物。

H2-N 通过也不直接解锁 H3，仍必须等待集中 PR-2B。
