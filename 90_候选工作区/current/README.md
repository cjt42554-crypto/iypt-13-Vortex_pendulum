## 候选内容

候选实现集中处理以下问题：

- 连续干湿尾流闭合与 exact-dry/near-dry 分离；
- 全干状态的水动力适用域旁路；
- 先求真实平衡、再执行结构线性化；
- 自由液面条带的严格干湿分类；
- 前向候选、二维截面参考和结构分析候选的模型身份分离。

## 运行入口

```bash
cd "90_候选工作区/current/候选实现"
npm ci
npm run validate
```

## 稳定边界

1. 候选实现与成熟 GUI、worker、DOPRI 和 CFD 主运行链保持分离，除非经过明确的组件回写。
2. 二维截面参考不能仅凭名称替代三维自由表面装置预测。
3. 未经装置标定的闭合参数不能形成实物定量预测资格。
4. 根目录 `01_最终理论/`、`02_模拟程序/`、`03_项目资料/` 是成熟基线。只有用户明确指定回写范围并完成相应验证时，才把候选组件写回成熟基线。
5. 任何 PASS、资格或预测声明只对其绑定的文件、提交、配置、命令和环境有效；本页不复制这些动态结论。
