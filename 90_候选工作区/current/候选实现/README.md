## 1. 已完成的工作

### 1.1 连续干湿尾流闭合

候选使用显式湿润状态和连续激活函数，使尾流频率、增长、立方饱和和结构—尾流耦合随湿润程度连续关闭。全干分支严格退化为尾流振幅的耗散衰减。

实现位置：

- `src/wetting.ts`
- `src/forward/model.ts`

`activationFraction` 的合同为 `0 < activationFraction <= 1`。默认值未经装置标定，必须随系数包保存和标定。

### 1.2 全干分支不再误触系数域外终止

全干状态由几何投影湿面积严格为零定义。`dryToleranceFraction` 只产生 near-dry 诊断；只有 exact-dry 旁路水动力系数域检查，其他适用域守卫保持有效。

### 1.3 结构分析先求真实平衡

候选先求 `F(X*)=0`，再计算平衡点 Jacobian。平衡残差、中心状态和完整五点模板任一硬门未通过时，谱分析拒绝继续。

实现位置：`src/structure/equilibrium.ts`。

### 1.4 二维 CFD 条带增加真实浸水门

当前二维后端只接受严格完全浸没的完整圆柱条带。全干、部分浸没、相切或共面条带均不构造载荷；湿面积分数只作为诊断量。

实现位置：`src/highFidelity/strip-wetting.ts`。

### 1.5 分离模型身份

本目录区分理论模型族、执行闭合包、前向数值候选、二维截面流体参考和结构分析候选。

实现位置：`src/model-identity.ts`。
