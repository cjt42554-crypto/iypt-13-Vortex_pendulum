# F1 前向数值资格结果前合同

## 1. 合同身份

合同身份为：

`VP-F1-SYNTHETIC-NUMERICAL-QUALIFICATION-CONTRACT-v1`

本合同只使用解析、合成或明确标记的示例系数。正式程序和正式理论保持只读。默认
`literature-prior` 不得标记为 `apparatus-calibrated`，也不得产生装置定量预测结论。

## 2. 冻结矩阵

轻量矩阵必须覆盖：

- 四状态 ODE 的三档步长收紧和解析参考；
- 湿几何积分的解析截面参考；
- 保守极限的能量余额；
- 已知根事件定位；
- 变惯量导数项的角加速度独立重算；
- 输出积分的解析参考；
- 相同输入的规范 payload 重复性；
- coefficient source 标签的正负例。

每个 case 必须记录 case ID、合同 SHA-256、实现 SHA-256、输入规范 SHA-256、参考身份、
平台身份、量化指标和结论码。合成矩阵不得读取 A8R 或真实实验数据。

## 3. 冻结门值

三档收紧中，四状态和位移相对参考误差必须单调下降。nominal 对 reference 的归一 RMS
不超过 `1e-3`，归一最大差不超过 `5e-3`。保守子问题最终相对能量余额不超过
`5e-5`，局部相对 RMS 不超过 `1e-4`。

事件根两细档差不超过 `max(10 * epsilon_t, 1e-6 s)`。加入惯量导数项后，两细档角
加速度相对差不超过 `1e-4`。输出积分的相对误差不超过 `1e-4`。

同一输入独立运行的规范数值 payload 必须逐字节一致。跨平台非逐字节差异只能按未来
单独冻结的合同处理，不能由本合同自动接受。

## 4. 短路和结论

任一输入非有限、来源标签冲突、矩阵缺 case、误差非单调、门值失败或规范 payload
漂移都必须 fail-closed。禁止结果后放宽门值、删点或改参考。

全部通过时最高结论为：

`PASS-F1-SYNTHETIC-NUMERICAL-QUALIFICATION-ONLY`

失败结论为：

- `NO-GO-F1-FORWARD-NUMERICAL-QUALIFICATION`；

该 PASS 不证明装置参数、公共流动物理、A8R 或实验预测。
