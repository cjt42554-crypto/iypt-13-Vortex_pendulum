# 实验前最小采集、标定与留出预测执行说明

## 1. 目的与模型边界

本执行包只服务于一个目标：使用装置实测参数和标定数据建立 `VP-FWD-P0-SL1-v1` 的装置系数包，并在读取预冻结留出结果之前给出带不确定度的现象预测。

A8S 的终局为：

`FREEZE-A8S-2D-CFD-QUALITATIVE-ONLY`

因此：

- 装置定量预测只使用正式 `forward` ROM；
- 二维 CFD 只可用于定性展示尾流结构或帮助解释残差；
- 二维 CFD 不得提供装置阻力、升力、力矩、振幅、平均功率或留出工况的定量标定值；
- 不再恢复 HW2R、H2-X/H2-N、H3、长时 A8R 或全候选性能资格。

本执行包不声称装置已经测量、ROM 已经标定或实验已经验证。它只闭合真实数据到位前仍可完成的输入定义、错误防护和正式配置桥接。

## 2. 四个输入文件与生产身份

复制并填写：

- `templates/apparatus-calibrated.template.json`；
- `templates/prediction-plan.template.json`；
- `templates/rom-coefficient-package.template.json`；
- `templates/trajectory.template.csv`。

正式配置生成只接受以下 classification：

- prediction plan：`experiment-frozen`；
- apparatus：`apparatus-calibrated`；
- ROM coefficients：`rom-calibrated`。

`synthetic-only` 只允许用于测试和合成资格，生产命令会拒绝。三个输入必须绑定同一个：

- `planId`；
- `apparatusId`；
- `apparatusRevision`。

系数包还必须显式记录 `predictionPlanId`、`apparatusId` 和 `apparatusRevision`。预测计划的 `freeze.frozenAt` 必须是有效时间戳，并保持 `holdoutOutcomesUnread=true`。

`conditionBlockId` 会进入输出文件名，只能使用 1 至 96 个 ASCII 字母、数字、点、下划线或连字符，且不能以点结尾。路径分隔符和 `..` 形式会被拒绝。

## 3. 水面几何必须显式给出

正式模型中的两个量彼此独立：

- `waterDepthM` 对应水槽水深 $H_0$，影响槽底间隙和深度 Froude 数；
- `pivotHeightM` 对应转轴高于未扰动水面的高度 $h_O$，直接决定圆柱湿润几何、排水体积和静水力矩。

改变加水量时，二者的关系取决于装置和水槽的实际坐标约定，构造器不再自动猜测。每一个 pilot、calibration 和 holdout block 都必须分别填写 `waterDepthM` 与 `pivotHeightM`。正式配置会分别写入：

- `geometry.waterDepth`；
- `geometry.pivotHeight`。

若水槽底和转轴固定、只改变水面高度，应依据实测水位同步计算两者；若采用其他实验操作，也必须按实际几何填写，不能只修改其中一个名义值。

## 4. 检查与配置生成

在 E1 目录执行：

```bash
npm test
npm run qualify:synthetic
npm run check:prediction-ready
```

空模板应得到：

`PASS-EXPERIMENT-PREPARATION-TOOLING-READY-WAITING-FOR-MEASUREMENTS`

该码只证明工具已准备好，并会列出仍依赖真实测量的数据；它不是实验 PASS。

真实输入完成后生成正式 forward 配置：

```bash
npm run build:forward-configs -- \
  --plan /path/prediction-plan.json \
  --apparatus /path/apparatus-calibrated.json \
  --coefficients /path/rom-coefficient-package.json \
  --base-config ../../../02_模拟程序/public/examples/vortex-pendulum-default.json \
  --output-dir /path/frozen-forward-configs
```

生产构造器拒绝：

- 空计划或装置身份；
- 未冻结计划；
- 三个输入绑定到不同装置或计划；
- synthetic-only 输入；
- calibration 与 holdout ID 重叠；
- 不安全的输出 ID；
- 不完整量值或标准不确定度；
- 工况位于系数包的流速、水深、转轴水面高度或 Reynolds 标定域之外；
- 初始角度或初始体动速度比位于正式 ROM 标定域之外；
- 尾流坐标规范漂移；
- 将二维 CFD 写成定量后端或系数来源；
- 无校准力矩通道却要求力—速度相位或平均功率符号。

## 5. 实验轨迹与装置量值

实验轨迹 CSV 的核心列为：

```text
run_id,time_s,theta_rad,displacement_m,sigma
```

`sigma` 对应本次比较所选观测量的标准不确定度。流速、水位、温度和可选力矩通道应在预测计划和原始采集文件中另行保存，不能只记录名义设定值。

装置记录至少覆盖：

- 圆柱半径、近端和远端站位；
- 转轴相对未扰动水面的高度；
- 水槽宽度和水深；
- 观测点位置和机械最大摆角；
- 随轴转动总成质量、质心和干转动惯量；
- 弹性参考角、线性刚度、黏性阻尼、库仑摩擦和摩擦平滑尺度；
- 水温、密度、运动黏度、表面张力和重力采用值。

每个量值保存中心值、单位、标准不确定度、测量方法和来源。照片像素不能直接当作米制长度，除非相机标定和透视修正已经完成。

## 6. 无流机械标定

在有流 ROM 拟合前先完成：

1. 空气或排水状态下的自由衰减；
2. 静水、零平均流下的自由衰减；
3. 每种状态至少三个初始幅值；
4. 每个幅值至少两个重复，建议三个。

按顺序识别平衡角、小振幅固有频率、有效惯量、线性刚度、黏性阻尼和库仑摩擦。只有多幅数据出现一致的幅值依赖残差时才考虑非线性刚度。

当不同初始幅值给出的机械参数在不确定度内一致、重复释放误差已量化、剩余残差不再呈清晰幅值依赖时，停止增加机械模型复杂度。

## 7. pilot、calibration 与 holdout

允许先做低成本 pilot，用于确定可见振荡区间、记录时长、相机帧率和量程，以及是否需要力矩通道。pilot 可用于实验设计，但不能事后改名为预冻结 holdout。

pilot 后、正式采集前冻结：

- 完整 condition block ID；
- 流速、水深、转轴水面高度、初始角度和释放方式；
- 记录时长和重复数；
- calibration/holdout 分组；
- 预测观测量和接受规则。

calibration 与 holdout 按完整 condition block 隔离，不能把同一次运行的时间帧随机拆到两侧。

最低建议：

- calibration 至少三个工况块，覆盖明显低于起振、接近转变和高于转变的区域；
- holdout 至少两个未用于拟合的工况块；
- 每个正式工况块至少两个重复，建议三个；
- 至少一个 holdout 改变初始幅值或释放条件，而不只是插值流速。

若 pilot 表明响应高度不稳定，应增加重复数，而不是增加模型自由参数。

## 8. 尾流坐标规范与参数识别

只观测角度或位移时，尾流状态 $A$ 的绝对幅值具有尺度自由度。当前固定 `unit-real-output-v1`：

- `rom.liftOutputReal = 1`；
- `rom.liftOutputImaginary = 0`；
- `rom.finiteSpanCoherence = 1`。

这只是坐标规范。只有独立、校准的力或力矩测量才能把该规范转换成具有物理载荷解释的输出系数，二维 CFD 不能解除该规范。

先固定几何、质量、质心、惯量、机械刚度和耗散、流体性质，以及没有证据的虚部耦合和直接力矩通道。然后优先辨识：

- 有效附加惯量；
- 有效阻力矩系数；
- Strouhal 关系；
- 尾流线性增长与饱和；
- 最少数量的机械—尾流耦合组合；
- 数据支持时的非线性频移。

若两个参数相关系数接近 $\pm1$，应固定其中一个或改用可辨识组合。本仓库不在真实 pilot 前预建通用高维优化器；数据到位后先冻结拟合参数组、残差权重、噪声模型和边界，再使用最小有界求解器。

## 9. 留出接受、数值误差与模型升级

每个 holdout 至少比较增长或衰减趋势、主频、振幅和建立时间。实际门取基础门和三倍实验相对标准不确定度中较大者：

$$
\varepsilon_f=\max(0.05,3u_{f,\mathrm{rel}}),
$$

$$
\varepsilon_A=\max(0.15,3u_{A,\mathrm{rel}}),
$$

$$
\varepsilon_{U_c}=\max(0.10,3u_{U_c,\mathrm{rel}}),
$$

$$
\varepsilon_T=\max(0.20,3u_{T,\mathrm{rel}}).
$$

增长或衰减趋势要求预测和实验的 95% 区间符号一致。只有存在校准力矩通道时，才比较力—速度相位和平均功率符号。

最终装置系数包至少执行三档 ODE 容差、湿几何、能量余额、事件根、参数扰动或后验传播，以及相同输入重复运行。当数值误差小于总预测区间宽度的大约三分之一，或明显小于参数和模型形式误差时，停止收紧数值设置。

只有留出残差在多个重复和相邻工况中表现出同一系统结构时，才允许一次增加一个机制。单个异常点、训练误差下降或二维 CFD 图像相似不能触发模型升级。

## 10. 实验前暂停边界

仓库达到工具层实验前可暂停，含义是：

- 二维 CFD 的定量去留已有终局；
- 正式 ROM、数值检查和实验比较工具可运行；
- 装置、系数、工况和接受规则有可填写模板与检查器；
- 身份错配、未冻结计划、synthetic 输入、路径逃逸、标定域越界和水面几何歧义会被拒绝；
- 冻结工况可生成正式 forward 配置；
- 剩余任务都需要真实装置、标定数据或留出结果。

数据到位前不再执行 HW2R、H2-X/H2-N、H3、长时 A8R、二维 CFD 参数追赶、三维 CFD、完整分岔工具、通用平台重构或无实际瓶颈的性能优化。
