# 实验前最小采集、标定与留出预测执行说明

## 1. 目的与边界

本执行包只服务于一个目标：使用装置实测参数和标定数据建立 `VP-FWD-P0-SL1-v1` 的装置系数包，并在读取预冻结留出结果之前给出带不确定度的现象预测。

A8S 的终局为：

`FREEZE-A8S-2D-CFD-QUALITATIVE-ONLY`

因此：

- 装置定量预测只使用正式 `forward` ROM；
- 二维 CFD 只可用于定性展示尾流结构或帮助解释残差；
- 二维 CFD 不得提供装置阻力、升力、力矩、振幅、平均功率或留出工况的定量标定值；
- 不再恢复 HW2R、H2-X/H2-N、H3、长时 A8R 或全候选性能资格。

本执行包不声称装置已经测量、ROM 已经标定或实验已经验证。它只闭合真实数据到位前仍可完成的输入定义、错误防护和正式配置桥接。

## 2. 文件与命令

复制并填写：

- `templates/apparatus-calibrated.template.json`；
- `templates/prediction-plan.template.json`；
- `templates/rom-coefficient-package.template.json`；
- `templates/trajectory.template.csv`。

实验轨迹 CSV 的核心列为：

```text
run_id,time_s,theta_rad,displacement_m,sigma
```

` sigma ` 对应本次比较所选观测量的标准不确定度。流速、水位、温度和可选力矩通道应在预测计划和原始采集文件中另行保存，不能只记录名义设定值。

检查工具：

```bash
cd 90_候选工作区/current/E1_实验准备与辨识协议
npm test
npm run qualify:synthetic
npm run check:prediction-ready
```

空模板应得到：

`PASS-EXPERIMENT-PREPARATION-TOOLING-READY-WAITING-FOR-MEASUREMENTS`

该码只证明工具已经准备好，并会列出仍依赖真实测量或标定的数据项；它不是实验 PASS。

完成装置记录、预测计划和 ROM 系数包后，生成正式 forward 配置：

```bash
npm run build:forward-configs -- \
  --plan /path/prediction-plan.json \
  --apparatus /path/apparatus-calibrated.json \
  --coefficients /path/rom-coefficient-package.json \
  --base-config ../../../02_模拟程序/public/examples/vortex-pendulum-default.json \
  --output-dir /path/frozen-forward-configs
```

构造器只接受预测计划中冻结的 calibration 和 holdout blocks，并拒绝：

- 未冻结工况；
- calibration 与 holdout ID 重叠；
- 未完成的量值或标准不确定度；
- 尾流坐标规范漂移；
- 将二维 CFD 标为定量后端或系数来源；
- 拟合期间读取留出结果；
- 无校准力矩通道却声称力—速度相位或平均功率符号。

## 3. 装置量值

`apparatus-calibrated.json` 必须覆盖正式模型实际消费的路径。

### 3.1 几何

至少测量：

- 圆柱半径；
- 圆柱近端、远端到转轴的距离；
- 转轴相对静水面的高度；
- 水槽宽度和水深；
- 观测标记点到转轴的距离；
- 机械允许最大摆角。

每个量值都要保存中心值、单位、标准不确定度、测量方法和来源。照片像素不能直接当作米制长度，除非相机标定和透视修正已经完成。

### 3.2 质量、质心和惯量

必须得到：

- 全部随轴转动总成的质量；
- 总成质心到轴的距离；
- 关于真实转轴的干结构转动惯量。

优先采用直接称量和几何测量、复摆或已知附加质量法，并用无流自由衰减作交叉约束。静水与空气结果的差异可约束附加惯量和静水耗散，但必须结合几何和不确定度解释。

### 3.3 支点和结构参数

记录弹性参考角、线性刚度、黏性阻尼、库仑摩擦和摩擦平滑尺度。只有多幅数据出现系统残差时才启用立方刚度；没有证据的项固定为零，不能为了降低训练误差随意加入。

### 3.4 流体和环境

每次实验至少记录水温、密度和运动黏度来源、表面张力采用值、水位，以及上游来流时间序列、实际均值、波动 RMS 和空间均匀性。泵档位不等于来流速度。

## 4. 无流机械标定

在有流 ROM 拟合前先完成：

1. 空气或排水状态下的自由衰减；
2. 静水、零平均流下的自由衰减；
3. 每种状态至少三个初始幅值；
4. 每个幅值至少两个重复，建议三个。

按顺序识别平衡角、小振幅固有频率、有效惯量、线性刚度、黏性阻尼和库仑摩擦。只有多幅数据出现一致的幅值依赖残差时才考虑非线性刚度。

当不同初始幅值给出的机械参数在不确定度内一致、重复释放误差已量化、剩余残差不再呈清晰幅值依赖时，停止增加机械模型复杂度。

## 5. pilot、calibration 与 holdout

允许先做一个低成本 pilot，用于确定可见振荡的大致流速区间、所需记录时长、相机帧率和量程，以及是否需要力矩通道。pilot 可用于实验设计，但不能事后改名为预冻结 holdout。

pilot 后、正式采集前冻结：

- 完整 condition block ID；
- 流速、水深、初始角度和释放方式；
- 记录时长和重复数；
- calibration/holdout 分组；
- 预测观测量和接受规则。

calibration 与 holdout 按完整 condition block 隔离，不能把同一次运行的时间帧随机拆到两侧。

最低建议：

- calibration 至少三个工况块，覆盖明显低于起振、接近转变和高于转变的区域；
- holdout 至少两个未用于拟合的工况块；
- 每个正式工况块至少两个重复，建议三个；
- 至少一个 holdout 改变初始幅值或释放条件，而不只是插值流速。

若 pilot 表明响应高度不稳定，应增加重复数，而不是增加模型自由参数。

## 6. 尾流坐标规范和可辨识性

只观测角度或位移时，尾流状态 $A$ 的绝对幅值具有尺度自由度。不能把尾流输出增益、耦合系数和立方饱和系数全部解释为独立绝对物理量。

本执行包固定 `unit-real-output-v1`：

- `rom.liftOutputReal = 1`；
- `rom.liftOutputImaginary = 0`；
- `rom.finiteSpanCoherence = 1`。

在该规范下，拟合得到的是装置角度数据可辨识的有效系数组合。只有独立、校准的力或力矩测量才能把该规范转换成具有物理载荷解释的输出系数。二维 CFD 的未通过定量基准的载荷不能解除这一规范。

## 7. ROM 参数识别顺序

先固定几何、质量、质心、惯量、机械刚度和耗散、流体性质，以及没有证据的虚部耦合和直接力矩通道。

然后优先辨识：

- 有效附加惯量；
- 有效阻力矩系数；
- Strouhal 关系；
- 尾流线性增长与饱和；
- 最少数量的机械—尾流耦合组合；
- 数据支持时的非线性频移。

若两个参数相关系数接近 $\pm1$，应固定其中一个或改用可辨识组合，而不是继续增加拟合维数。

本仓库不在真实 pilot 前预建通用高维优化器。参数组、残差权重、噪声相关、正则化和不确定度算法依赖实际通道、采样率和 pilot 残差。数据到位后先冻结这些选择，再实现或调用最小有界求解器。

只有留出残差在多个重复和相邻工况中表现出同一系统结构时，才允许一次增加一个机制，例如流速依赖的相干系数、第二尾流模态、额外时延、非线性阻力或自由表面/三维端部修正。单个异常点、训练误差下降或二维 CFD 图像相似不能触发模型升级。

## 8. 留出预测与接受规则

每个 holdout 至少比较：

- 增长或衰减趋势；
- 主频；
- 振幅；
- 建立时间。

实际门取基础门和三倍实验相对标准不确定度中较大者：

$$
\varepsilon_f=\max(0.05,3u_{f,\mathrm{rel}}),
$$

$$
\varepsilon_A=\max(0.15,3u_{A,\mathrm{rel}}),
$$

$$
\varepsilon_{U_c}=\max(0.10,3u_{U_c,\mathrm{rel}}),
$$

$$
\varepsilon_T=\max(0.20,3u_{T,\mathrm{rel}}).
$$

增长或衰减趋势要求预测和实验的 95% 区间符号一致。只有存在校准力矩通道时，才比较力—速度相位和平均功率符号；相位基础门为：

$$
\varepsilon_\phi=\max(0.2\ \mathrm{rad},3u_\phi).
$$

## 9. 数值和不确定度

对最终装置系数包至少运行：

- 三档 ODE 容差；
- 湿几何检查；
- 能量余额；
- 事件根检查；
- 参数扰动或后验样本传播；
- 相同输入重复运行。

当数值误差已小于总预测区间宽度的大约三分之一，或明显小于参数和模型形式误差时，停止继续收紧数值设置。

预测报告必须分别列出数值误差、参数不确定度、测量不确定度和模型形式情景。不得用更小时间步替代未标定系数或缺失物理。

## 10. 实验前暂停边界

仓库达到工具层实验前可暂停，含义是：

- 二维 CFD 的定量去留已有终局；
- 正式 ROM、数值检查和实验比较工具可运行；
- 装置、系数、工况和接受规则有可填写模板与检查器；
- calibration/holdout 泄漏、尾流规范漂移、CFD 定量误用和无力矩功率主张可被拒绝；
- 冻结工况可生成正式 forward 配置；
- 剩余任务都需要真实装置、标定数据或留出结果。

数据到位前不再执行 HW2R、H2-X/H2-N、H3、长时 A8R、二维 CFD 参数追赶、三维 CFD、完整分岔工具、通用平台重构或无实际瓶颈的性能优化。
