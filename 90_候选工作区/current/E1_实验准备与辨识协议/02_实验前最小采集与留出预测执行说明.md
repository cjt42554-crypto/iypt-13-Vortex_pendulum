# 实验前最小采集、标定与留出预测执行说明

## 1. 目的和当前模型边界

本文件把已有理论、正式前向求解器和 E1/F1/S1 工具收缩成一条可直接执行的个人实验流程。目标只有一个：

> 用装置实测参数和标定数据建立 `VP-FWD-P0-SL1-v1` 的装置系数包，并在读取预冻结留出结果前给出带不确定度的现象预测。

当前二维 CFD 的终局为：

`FREEZE-A8S-2D-CFD-QUALITATIVE-ONLY`

因此：

- 装置定量预测只使用正式 `forward` ROM；
- 二维 CFD 只可展示定性尾流结构或帮助解释残差；
- 二维 CFD 不得提供装置阻力、升力、力矩、幅值、平均功率或留出预测的定量标定值；
- 不再恢复 HW2R、H2-X/H2-N、H3、长时 A8R 或全候选性能资格。

本执行包不声称装置已经测量、ROM 已经标定或留出预测已经通过。它只证明：在真实数据到位前仍可完成的输入定义、错误防护和正式配置桥接已经具备。

## 2. 文件与命令

### 2.1 需要填写的三个文件

复制并填写：

- `templates/apparatus-calibrated.template.json`；
- `templates/prediction-plan.template.json`；
- `templates/rom-coefficient-package.template.json`。

实验轨迹可从：

`templates/trajectory.template.csv`

开始记录。该 CSV 与正式程序现有实验导入的核心列兼容：

```text
run_id,time_s,theta_rad,displacement_m,sigma
```

同一文件中的 `sigma` 对应本次比较所选观测量的标准不确定度。流速、水位、温度和可选力矩通道应在预测计划及原始采集文件中另行保留，不能只写一个名义设定值。

### 2.2 检查工具本身

```bash
cd 90_候选工作区/current/E1_实验准备与辨识协议
npm test
npm run qualify:synthetic
npm run check:prediction-ready
```

最后一条命令对空模板应给出：

`PASS-EXPERIMENT-PREPARATION-TOOLING-READY-WAITING-FOR-MEASUREMENTS`

同时列出仍依赖真实测量或标定的数据项。它不是实验 PASS。

### 2.3 生成正式 forward 配置

完成装置记录、预测计划和 ROM 系数包后：

```bash
cd 90_候选工作区/current/E1_实验准备与辨识协议

npm run build:forward-configs -- \
  --plan /path/prediction-plan.json \
  --apparatus /path/apparatus-calibrated.json \
  --coefficients /path/rom-coefficient-package.json \
  --base-config ../../../02_模拟程序/public/examples/vortex-pendulum-default.json \
  --output-dir /path/frozen-forward-configs
```

该命令只为预测计划中冻结的 calibration 和 holdout blocks 生成配置，并拒绝：

- 未在计划中冻结的工况；
- calibration 与 holdout ID 重叠；
- 未完成的量值或标准不确定度；
- 尾流坐标规范漂移；
- 把二维 CFD 标为定量后端；
- 拟合期间读取留出结果；
- 将 `hf-calibrated` 作为装置 ROM 系数来源。

## 3. 装置量值

`apparatus-calibrated.json` 必须覆盖正式模型实际消费的全部装置路径。

### 3.1 几何

至少测量：

- 圆柱半径；
- 圆柱近端和远端到转轴的距离；
- 转轴相对静水面的高度；
- 水槽宽度和水深；
- 观测标记点到转轴的距离；
- 机械允许最大摆角。

每个量值保存：

- 中心值；
- 单位；
- 标准不确定度；
- 测量方法；
- 数据来源。

不能从照片像素直接填入米制长度，除非对应相机标定和透视修正已经完成。

### 3.2 质量、质心和惯量

必须得到：

- 全部随轴转动总成的质量；
- 总成质心到轴的距离；
- 关于真实转轴的干结构转动惯量。

优先顺序为：

1. 直接称量和几何测量；
2. 双线摆、复摆或已知附加质量法测惯量；
3. 与无流自由衰减联合拟合。

醙水与空气结果的差异可以纵教附加惯量及醙水耗散，但两者保结合几何和不确定度解释。

### 3.3 支点和结构参数

必须记录：

- 弹性参考角；
- 线性刚度；
- 有证据时才启用的立方刚度；
- 黏性阻尼；
- 库仑摩擦；
- 摩擦平滑尺度。

无证据时，立方刚度和未观测的耦合项固定为零，而不是自由加入拟合。

### 3.4 流体和环境

每次实验至少记录：

- 水温；
- 密度和运动黏度的来源；
- 表面张力的采用值及来源；
- 水位；
- 上游来流时间序列；
- 名义流速、实际均值、波动 RMS 和空间均匀性。

只记录泵档位不等于记录来流速度。

## 4. 无流机械标定

在有流 ROM 拟合前先完成机械标定。

### 4.1 建议矩阵

至少执行：

1. 空气或排水状态下的自由衰减；
2. 静水、零平均流下的自由衰减；
3. 每种状态至少三个初始幅值；
4. 每个幅值至少两个重复，建议三个。

### 4.2 需要识别的对象

按顺序识别：

1. 平衡角；
2. 小振幅固有频率；
3. 有效惯量；
4. 线性刚度；
5. 黏性阻尼；
6. 库仑摩擦；
7. 只有多幅数据出现系统残差时才考虑立方刚度。

静水与空气结果的差异可以约束附加惯量和静水耗散，但两者仍需结合几何和不确定度解释。

### 4.3 停止条件

当：

- 不同初始幅值给出的机械参数在不确定度内一致；
- 重复释放误差已经量化；
- 剩余残差不再呈清晰幅值依赖；

即停止增加机械模型复杂度。

## 5. pilot、calibration 和 holdout

### 5.1 pilot

允许先做一个低成本 pilot 以定位：

- 可见振荡的大致流速区间；
- 所需记录时长；
- 相机帧率和量程；
- 是否需要力矩通道。

pilot 可以用于实验设计，但不能被事后改名为预冻结 holdout。

### 5.2 正式冻结

pilot 后、正式 calibration 与 holdout 采集前，必须冻结：

- 完整 condition block ID；
- 流速、水深、初始角度和释放方式；
- 记录时长和重复数；
- calibration/holdout 分组；
- 预测观测量和接受规则。

calibration 和 holdout 按完整 condition block 隔离，不能把同一运行的时间帧随机拆分到两侧。

### 5.3 最小工况数

最低建议：

- calibration：至少三个工况块，覆盖明显低于起振、接近转变和高于转变的区域；
- holdout：至少两个未用于拟合的工况块；
- 每个正式工况块至少两个重复，建议三个；
- 至少一个 holdout 改变初始幅值或释放条件，而不只插值流速。

若 pilot 表明响应高度不稳定，应增加重复数，而不是增加模型自由参数。

## 6. 尾流坐标规范和可辨识性

只观测角度或位移时，尾流状态 $A$ 的绝对幅值具有尺度自由度。不能同时把：

- 尾流输出增益；
- 耦合系数；
- 立方饱和系数；

全部解释为独立物理绝对量。

本执行包固定规范：

`unit-real-output-v1`

即：

- `rom.liftOutputReal = 1`；
- `rom.liftOutputImaginary = 0`；
- `rom.finiteSpanCoherence = 1`。

在该规范下，拟合得到的是装置角度数据所辨识的有效系数组合。只有独立、校准的力或力矩测量才能把该规范转换成具有物理载荷单位解释的输出系数。

不得用二维 CFD 的未通过定量基准的载荷来解除这一规范。

## 7. ROM 参数识别顺序

使用尽可能少的自由参数。

### 7.1 先固定或测量

先固定：

- 几何、质量、质心、惯量；
- 机械刚度和耗散；
- 水温对应的流体性质；
- 未观察到的虚部耦合；
- 无证据的直接力矩通道。

### 7.2 再辨识

优先辨识：

- 有效附加惯量；
- 有效阻力矩系数；
- Strouhal 关系；
- 尾流线性增长与饱和；
- 最少数量的机械—尾流耦合组合；
- 数据支持时的非线性频移。

若两个参数相关系数接近 $\pm1$，应固定其中一个或改用可辨识组合，而不是继续扩大数据拟合维数。

本仓库不在真实 pilot 之前预建一个通用高维优化器。参数组、残差权重、噪声相关结构、正则化和不确定度算法都依赖实际通道、采样率和 pilot 残差；提前冻结一个通用优化器更可能制造不可辨识拟合，而不是提高预测准确度。pilot 数据到位后，应先冻结这些选择，再实现或调用最小的有界拟合器。该事项因此属于数据触发任务，不是当前尚可执行的非实验缺口。

### 7.3 模型升级

只有留出残差在多个重复和相邻工况中表现出同一系统结构时，才允许一次增加一个机制，例如：

- 流速依赖的相干系数；
- 第二尾流模态；
- 额外时延；
- 非线性阻力；
- 自由表面或三维端部修正。

单个异常点、训练误差巻个重复和相邻工况中表现出同一系统结构时，才允许一次增加一个机制，例如：

- 流速依赖的相干系数；
- 第二尾流模态；
- 额外时延；
- 非线性阻力；
- 自由表面或三维端部修正。

单个异常点、训练误差下降或二维 CFD 图像相似不能触发模型升级。

## 8. 留出预测和接受规则

### 8.1 无条件必测

每个 holdout 至少比较：

- 增长或衰减趋势；
- 主频；
- 振幅；
- 建立时间。

### 8.2 误差上限

在真实通道不确定度确定后，实际门取“基础门”和“三倍实验相对标准不确定度”中较大者：

$$
\varepsilon_f
=
\max(0.05,3u_{f,\mathrm{rel}}),
$$

$$
\varepsilon_A
=
\max(0.15,3u_{A,\mathrm{rel}}),
$$

$$
\varepsilon_{U_c}
=
\max(0.10,3u_{U_c,\mathrm{rel}}),
$$

$$
\varepsilon_T
=
\max(0.20,3u_{T,\mathrm{rel}}).
$$

这些基础值是当前个人实验的起始工作门，不是普适精度声明。

增长/衰减趋势要求预测与实验的 95% 区间给出相同符号。若区间包含零，应记为不确定，而不是强行判定。

### 8.3 相位和平均功率

只有存在校准的力或力矩通道，或有独立验证的逆动力学力矩重构时，才允许比较：

- 力—速度相位；
- 平均流体功率符号。

没有力矩通道时，不得仅凭角度轨迹声称平均流体功率符号。相位的基础门为：

$$
\varepsilon_\phi
=
\max(0.2\ \mathrm{rad},3u_\phi).
$$

## 9. 数值和不确定度

对最终装置系数包至少运行：

- 三档 ODE 容差；
- 湿几何检查；
- 能量余额；
- 事件根检查；
- 参数扰动或后验样本传播；
- 相同输入重复运行。

当数值误差已经小于总预测区间宽度的约三分之一，或明显小于参数和模型形式误差时，停止进一步收紧数值设置。

预测报告必须分别列出：

- 数值误差；
- 参数不确定度；
- 测量不确定度；
- 模型形式情景。

不能用更小时间步替代未标定系数或缺失物理。

## 10. 实验前暂停边界

仓库工具层达到实验前可暂停，不表示科学预测已经完成。其含义是：

- 二维 CFD 的定量去留已经有终局；
- 正式 ROM、数值检查和实验比较工具可运行；
- 装置、系数、工况和接受规则的全部必要输入已有模板与检查器；
- calibration/holdout 泄漏、尾流规范漂移、CFD 定量误用和无力矩功率主张会被拒绝；
- 冻结工况可以自动生成正式 forward 配置；
- 后续所有实质任务都需要真实装置测量、标定数据或留出结果。

在取得真实数据前，不再执行：

- HW2R、H2-X/H2-N 或 H3；
- 长时 A8R；
- 二维 CFD 继续调参追赶文献；
- 通用软件平台重构；
- 完整结构分岔和混沌工具；
- 为形式完整增加新的合同、通过码或证据层。

数据到位后的顺序是：

1. 填写装置记录；
2. 冻结 calibration/holdout 计划；
3. 完成机械标定；
4. 形成装置 ROM 系数包和不确定度；
5. 生成并提交 holdout 预测；
6. 再读取 holdout 实验结果；
7. 裁定预测误差和是否需要一个明确的新物理机制。
