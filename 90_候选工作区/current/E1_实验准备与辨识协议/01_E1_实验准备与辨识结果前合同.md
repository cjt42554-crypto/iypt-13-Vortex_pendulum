# E1 实验准备与辨识结果前合同

## 1. 合同身份与结论边界

合同身份为：

`VP-E1-EXPERIMENT-PREPARATION-CONTRACT-v1`

本合同在任何真实实验数据采集、装置参数拟合或留出集读取之前冻结。它建立可执行的
计量、同步、数据、辨识、不确定度和安全接口，但不声称装置已经建成、校准或验证。

允许的最高结论为：

`PASS-E1-EXPERIMENT-PREPARATION-CANDIDATE-ONLY`

## 2. 机器记录集合

E1 使用以下不可混用的记录：

1. apparatus：装置版本、BOM、几何、装配公差和所有装置参数；
2. calibration：相机、编码器、载荷、流速、长度和水位标定；
3. run-record：固定体、规定运动、无流机械、自由响应和留出工况；
4. timeseries：原始或派生通道的长表记录；
5. identification：参数组合、先验、正则化、训练块、留出块和不确定度。

所有物理量必须同时具有数值、单位、来源、时间戳和标准不确定度。由其他量推导的值
还必须列出上游记录哈希。示例文献先验不得标为 measured、calibrated 或
apparatus-calibrated。

## 3. 同步、校准与数据完整性

每个 run 必须绑定不可变配置 SHA-256、原始数据 SHA-256、装置版本和有效校准 ID。
同一时间轴必须显式记录时钟源、延迟估计、同步标准不确定度和时间零点。相机记录还要
保存折射、透视、滚动快门和滤波策略；禁止用处理后数据覆盖原始数据。

验证器必须拒绝：

- 缺单位、缺来源、缺时间戳或缺不确定度；
- 非有限值、时间倒退、重复主键和未知通道；
- 缺失、过期或装置版本不匹配的校准；
- 将角度通道当位移通道或反之；
- 缺配置哈希、原始数据哈希或安全状态；
- 训练块与留出块交叠；
- 按时间帧随机拆分同一工况块。

## 4. 运行矩阵和留出冻结

运行族必须覆盖 fixed-body、prescribed-motion、no-flow-mechanical、free-response 和
holdout。留出集在任何拟合前按完整 condition block 冻结；同一 block 的帧、重复或
相邻截段不得跨越训练与留出边界。

首次真实采集前必须生成 run manifest，并在采集后保留失败、停止、缺失和未开始记录，
不得重编号或删除来制造完整矩阵。

## 5. 合成资格门

合成生成器只产生已知、非装置的测试数据。必须同时通过：

- 规范 JSON round-trip 字节一致；
- 所有正例被接受，所有预注册负例被拒绝；
- 已知合成参数估计误差落入 `max(2u_num, 2u_fit)` 包络；
- 训练和留出按 block 隔离；
- 相同输入生成相同规范字节；
- 报告显式标记 `synthetic-only`。

## 6. 安全与停止

真实实验模板必须包含人员、急停、最大角度、最大位移、最大载荷、水电隔离、溢流、
相机和电缆固定、数据备份及异常停机字段。任一必需检查未知或失败时不得开始 run。

本 G1 批次只验证合同和合成数据；不操作真实装置，不采集真实数据，不形成物理系数或
装置趋势。
