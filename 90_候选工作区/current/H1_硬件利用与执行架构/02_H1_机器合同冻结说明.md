## 1. 身份

机器合同身份为：

`VP-A8R-HW1-MACHINE-CONTRACT-v1`

它是冻结文件 `01_A8R_HW1_结果盲硬件资格预注册合同.md` 的机器可读映射，不修改、
放宽或取代该 Markdown 合同。若两者冲突，必须 fail-closed，并新建版本，禁止结果后
修改 v1。

## 2. 映射范围

机器合同固定以下部分：

- H0、H1、H2、H3 的阶段顺序；
- 当前串行参考隔离边界；
- 允许和禁止的字段；
- CPU、GPU、混合、SIMD/native、调度与数据平面的候选覆盖义务；
- inventory、重复性、正确性、性能、资源、内存和热管理门；
- H2-X 精确等价和 H2-N 另行预注册语义；
- shard、确定性聚合和三层 provenance；
- 两个新鲜全量环境和所有失败短路码。

合同测试必须逐项验证固定标量、集合、禁止字段和阶段迁移。任何未知字段、自动
fallback、科学字段泄漏、缺失或重复 shard、来源漂移以及结果身份混用都必须失败。

## 3. 无结果边界

H1 实现只能生成伪科学 payload 的摘要哈希和相同/不同布尔值。测试所用 payload 是
固定合成字节，不来自 A8R 运行。PID、计时、硬件和资源指标只能进入 execution 层，
不能进入 scientific 层。

本合同不授权 H2 性能 probe，不授权 D54、GPU 或内存带宽负载，也不授权读取正在运行
的串行参考科学结果。
