# 未提交修改

这是本仓库唯一的默认工作区。

“未提交”表示这里的内容尚未提交或晋升到 `01-最终理论`、`02-模拟程序`、`03-项目资料`，不表示 Git 工作必须保持未提交。为了供 Codex 和网页版 Pro 从 GitHub 接力，阶段成果仍应在验证和交接后正常 commit、push。

当前只允许一个权威活动任务：[`当前任务/README.md`](./当前任务/README.md)。

目录规则：

- `当前任务/候选实现/`：可执行或可审查的候选内容；
- `当前任务/管理/`：活动验收清单、变更映射、修改记录和验证记录；
- `当前任务/审查与复现/当前审查/`：当前审查入口及冻结同步包；
- `当前任务/审查与复现/历史审查/`：绑定旧提交的历史裁决和证据。

历史审查中的旧路径和旧命令只描述其绑定提交，不是当前活动路径。新任务不得直接照抄历史命令，应从当前任务入口读取现行命令。

未经用户明确授权，本目录中的任何内容都不得覆盖三个成熟目录。
