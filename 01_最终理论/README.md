# 理论

本目录包含涡流摆研究的四份理论文档：

1. [`01-前向预测理论.md`](01-前向预测理论.md)：定义给定装置参数与初态后的前向预测模型。
2. [`02-前向预测理论的数值计算理论.md`](02-前向预测理论的数值计算理论.md)：说明离散、求解和数值误差控制。
3. [`03-结构性理论.md`](03-结构性理论.md)：研究平衡、稳定性、模态、分岔及其他结构性质。
4. [`04-实验辨识、标定与留出预测协议.md`](04-实验辨识、标定与留出预测协议.md)：规定装置量值、ROM 辨识、不确定度传播、预测冻结和留出证伪。

前向理论保留 `VP-FWD-P0-SL1-v1` 基线，并给出 SS 低速粘滑、DW 方向湿宽及显式组合分支。第 6 节区分规范不变量与可辨识条件，第 12–13 节给出替换方程、能量及适用域。数值和结构文档的原有光滑结论不自动覆盖这些分支；各分支需按实验协议绑定独立系数身份。

四份文档分别承担物理模型、数值方法、结构分析和实验预测协议。目录名称不构成数值收敛、预测精度或实验有效性的证明；相关结论必须由相应验证支持。

维护权限与交接方式统一见 [根工作规范](../AGENTS.md) 和 [目录指南](../00_项目管理/README.md)。本文件只描述科学/技术接口，不另设审批要求。
